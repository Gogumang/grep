# grep

**기술 블로그 읽기. 여러 회사의 새 글을 한곳에서 훑고, 찾고, 그 자리에서 읽습니다.**

→ **https://grep-alpha.vercel.app**

---

## 읽는 흐름

**훑기** — 첫 화면 맨 위의 *오늘의 픽*은 블로그가 겹치지 않게 고릅니다.
한 회사 글이 몰려서 나머지를 덮는 일이 없습니다. 그 아래로 최신 글이 이어지고,
왼쪽에서 분류(Engineering·Design 등)와 블로그 이름으로 좁힐 수 있습니다.

**찾기** — `⌘K`(또는 헤더의 돋보기)로 검색창이 열립니다. 제목만이 아니라
**글 본문 전체**를 찾기 때문에 "그때 캐시 얘기 나온 글이 어디였더라"가 됩니다.
손을 키보드에서 뗄 일이 없습니다 — 방향키로 결과를 오르내리고, `Enter`로 열고,
`Esc`로 닫습니다.

**읽기** — 목록에서 글을 열면 본문이 그 자리에서 읽힙니다.
코드 블록과 이미지도 원문 그대로입니다. 탭을 새로 열고 로딩을 기다릴 필요가 없습니다.

## 읽는 걸 방해하지 않으려고 한 것들

읽기 좋은 사이트는 기능이 많은 사이트가 아니라 **걸리적거리지 않는 사이트**입니다.
그래서 이런 것들을 챙겼습니다.

- **깜빡이지 않는 다크 모드** — 화면이 그려지기 전에 테마가 정해집니다.
  다크 모드로 들어왔는데 흰 화면이 한 번 번쩍이는 일이 없습니다.
  처음엔 OS 설정을 따르고, 한 번 바꾸면 그 선택을 기억합니다.
- **필요할 때만 받는 검색** — 검색을 쓰지 않는 사람은 검색 코드를 내려받지 않습니다.
  검색창을 처음 열 때 받아옵니다.
- **가벼운 글 페이지** — 글을 읽는 화면에는 UI 프레임워크가 없습니다(압축 후 2.1KB).
  본문이 뜨기까지 기다릴 자바스크립트가 없습니다.
- **줄어든 이미지** — 썸네일도 본문 이미지도 원문 서버에서 받아 AVIF로 다시 만들어
  함께 내보냅니다(246장, 90MB → 8.7MB). 원문이 이미지를 지워도 글이 비지 않고,
  읽는 사람의 브라우저가 원문 서버로 요청을 보내지 않습니다.
  `bun run images`로 새로 수집된 글의 이미지를 받아옵니다.
- **화면 크기를 가리지 않음** — 폰에서 목록을 훑다가 노트북에서 이어 읽어도 같습니다.

## 원문이 먼저입니다

남의 글을 옮겨 싣는 곳이라, 읽는 사람과 쓴 사람 모두에게 정직하려고 합니다.

- 모든 글에 **글쓴이와 출처 블로그**를 함께 답니다
- 글 위에 **원문에서 보기** 링크를 둡니다
- 검색엔진과 AI에게 **정본은 원문이라고 알립니다**(`canonical`이 원문을 가리킵니다)

여기는 찾는 곳이고, 읽는 곳은 원문이어도 좋습니다.
