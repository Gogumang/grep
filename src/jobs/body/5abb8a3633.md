### 합류하게 될 팀에 대해 알려드려요  
- 토스증권 Data Engineer(금융데이터/자문)는 WM Domain의 Advisory Silo 소속이에요. Advisory Silo는 소수 자산가의 전유물이었던 자산관리를 모두의 것으로 만들기 위해, 투자 전략 마켓플레이스와 AI 기반 자문·일임 서비스를 만드는 팀이에요.  
- 자문·일임 서비스의 신뢰는 데이터에서 시작돼요. 국내외 운용사·자문사 파트너의 투자 전략 데이터부터 고객의 거래·자산·행동 데이터까지, 전략의 생성 → 검증 → 분석을 관통하는 데이터 스트림을 만들고, 이를 기반으로  자산관리 콘텐츠 제공부터 포트폴리오 추천까지 이어지는 흐름의 데이터를 설계/운영하는 것이 이 포지션의 역할이에요.  
- 기획,디자인, 개발, 데이터, 운영이 한 팀으로 빠르게 실험하고 실행하는 조직이에요.

### 합류하면 함께 할 업무예요  
- 운용사·자문사 등 파트너로부터 포트폴리오 데이터(종목 구성, 리밸런싱 시그널 등)를 수신·검증·적재하는 파이프라인을 구축하고, 장애 대응·백필·모니터링 등 운영 전반을 담당해요.  
- 고객 계좌의 포트폴리오 운용성과(수익률·리스크·벤치마크 대비 성과)를 산출하는 파이프라인을 개발하고, 산출 결과의 정확성을 검증해요. 자문·일임 서비스에서는 숫자 하나의 오류가 고객 자산과 직결되기 때문에, 정확성이 곧 서비스 품질이에요.  
- 토스증권 고객의 매매·보유자산·정보탐색행동 데이터를 분석 하여 고객을 유형화할 수 있는 피처 데이터를 만들어요. 마이데이터와 증권과 관련된 금융 데이터를 결합해 고객 자산 현황을 분석하고, 이를 활용해 고객별 맞춤형 투자전략을 추천할 수 있도록 고객 피쳐·데이터를 만들어요.  
- 고객의 자문 콘텐츠(운용사 브랜드관, 리포트 등) 소비 행동 데이터를 분석하여 추천 시스템으로 이어주는 데이터 서빙 구조를 만들어요. 이를 활용하여 고객의 콘텐츠 소비 패턴을 기반으로 투자 전략을 추천하고, 추천받은 자문으로 고객이 쉽게 포트폴리오 가입으로 이어지는 흐름의 데이터 기반을 담당해요.  
- 파트너별로 다른 종목 식별자(티커, ISIN 등)를 사내 표준 식별자와 매핑하고, 티커 변경·상장폐지·기업 액션 등 다양한 이벤트에 대응하며 데이터를 관리해요.  
- 원천 데이터와 가공 데이터 사이의 정합성·완전성·적시성을 검증하는 품질 체계를 구축해요. 금융 규제(자문·일임) 환경에서 요구되는 수준의 데이터 신뢰성을 만들어가요.

### 이런 분과 함께하고 싶어요  
- 3년 이상의 데이터 엔지니어링 실무 경험이 있으신 분, 금융 데이터 처리 경험이 있다면 더 좋아요.  
- Python, SQL 기반의 데이터 수집·가공 역량이 필요해요.  
- 외부 API 및 파일 연계 기반 수집 시스템을 직접 설계·구현해본 경험이 필요해요.  
- Airflow 등 배치 파이프라인을 개발·운영해본 경험이 필요해요.  
- RDBMS 및 분산 데이터 환경(Iceberg, Spark, ClickHouse, Kafka 등)에서 데이터를 처리해본 경험이 필요해요.  
- 데이터 정합성·품질 문제를 단순 오류 수정에 그치지 않고, 데이터 구조와 도메인 맥락 관점에서 원인을 추적해 근본적으로 해결해본 경험이 필요해요.
