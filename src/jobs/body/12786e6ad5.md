### 합류하게 될 팀에 대해 알려드려요  
인터뷰 과정에서 확인된 지원자의 강점과 회사의 상황을 종합적으로 고려하여, 가장 적합한 조직에 배치될 예정이에요.

[대출 신청/심사]  
- 토스뱅크 Server Developer (대출 신청/심사)는 Product Owner/Product Designer/Frontend Developer/Data Analyst 등 다양한 직군의 동료들과 함께 스쿼드(팀)를 이루어 함께 서비스를 개발해요.  
- 토스뱅크만의 고유한 개발 문화와 자율적인 환경에서, 기존 뱅킹 서비스의 한계를 뛰어넘는 최고의 서비스를 개발하기 위해 노력해요.  
- 토스뱅크를 이용하는 고객들이 더 편리하고 만족스러운 금융 경험을 할 수 있도록 끊임없이 고민하고 개선해 나가요.  
- 대출 신청/심사 영역은 MDD 기반으로 구성된 서비스를 Kotlin, Spring으로 구성된 시스템으로 전환하고 있어요.

[대출 실행/상환]  
- 토스뱅크 Server Developer (대출 실행/상환)는 대출 실행/상환 도메인 전담팀에 소속되어, 개인/기업/전세 등 다양한 대출 스쿼드, 회계팀, 사후관리팀과 긴밀히 협업해요.  
- 하나의 팀에서 은행 시스템의 전체 흐름을 처음부터 끝까지 실무로 경험할 수 있는 환경이며, 단순 처리 중심이 아닌, 정책 기반 도메인을 기술적으로 구조화하는 설계 중심 팀이에요.  
- 대출 실행부터 상환까지 고객 신뢰와 직결되는 정교한 흐름을 하나의 도메인 관점에서 통합적으로 설계해요.  
- 현재는 모놀리식 코어뱅킹 시스템을 단계적으로 MSA로 전환하는 마이그레이션 과정에 있어요. 기존 시스템을 안정적으로 운영하면서도, 새로운 구조를 주도적으로 설계하고 전환해 나가고 있어요.

[사후관리]  
- 토스뱅크 Server Developer (대출 사후관리)는 대출 사후관리 도메인 전담팀에 소속되어 사후 단계의 모든 흐름을 책임지는 핵심 영역이에요.  
- 연체 및 추심 스케줄 수립, 고객 상태 관리, 법적 절차 연계, 회계 반영과 최종 상각 처리까지 금융기관의 건전성 관리와 직결되는 영역을 도메인 관점에서 통합적으로 설계하고 운영하고 있어요.  
- 하나의 팀에서 여신 실행 이후의 전체 흐름을 처음부터 끝까지 경험할 수 있는 환경이며, 단순한 업무처리 중심이 아닌 정책 중심의 사후관리 도메인을 기술적으로 구조화하는 설계 중심 팀이에요.  
- 현재는 모놀리식 코어뱅킹 시스템을 단계적으로 MSA로 전환하는 마이그레이션 과정에 있어요. 기존 시스템을 안정적으로 운영하면서도, 새로운 구조를 주도적으로 설계하고 전환해 나가고 있어요.

### 합류하면 함께할 업무예요  
- 토스뱅크의 모든 여신 상품(신용, 기업, 전세 등)에 대한 신청·심사·금리 산출·실행·상환·사후관리 도메인을 각 파트별로 전담해요.  
- MDD(Model Driven Development) + Java 기반 모놀리식 코어뱅킹 시스템을 안정적으로 유지하면서, Kotlin + Spring Boot 기반의 MSA 구조로 단계적으로 전환해요.  
- 영업점 없는 환경에서 대출 시스템 전체 흐름이 사람 없이 이루어질 수 있도록 프로세스를 설계하고 자동화해요.  
- 정책 중심 로직을 도메인 기반 구조로 재해석하고 리팩토링하며, 법령 변화·정책 변경·운영 요구까지 아우를 수 있는 지속 가능한 설계 구조로 발전시켜 나가요.  
- 고정밀 수치 계산과 실시간 처리 요구를 만족시키는 환경 속에서, 데이터 정합성·트랜잭션 처리·이벤트 연계 등 마이크로서비스 설계의 핵심 요소들을 직접 설계하고 구현해요.  
- 반복되는 정책 분기와 다양한 케이스를 기준화하여 팀 내 설계 기준을 세우고, 확장 가능한 고가용성 구조를 직접 구축해요.

### 이런 분과 함께하고 싶어요  
- 복잡한 비즈니스 흐름이나 경험해보지 못한 기술 스택도 빠르게 학습하고 흡수하려는 태도를 갖춘 분이 필요해요.  
- 문제의 본질을 파악하고, 실질적인 해결에 집중하는 분이 필요해요.  
주어진 요구를 그대로 구현하기보다, 스스로 기준을 세우고 마주한 문제를 구조적으로 개선해 본 경험이 있는 분이 필요해요.  
- 유관부서와의 협업에서 소통에 책임감을 가지고, 함께 해법을 만들어가는 분이면 좋겠어요.  
변화를 두려워하지 않고 지속적인 성장을 원하시는 분이면 좋아요.  
- 금융권이나 복잡한 정책 기반 시스템에서의 운영·개발 경험이 있다면 더욱 좋아요.

### 이런 경험이 있다면 더욱 좋아요  
- Kotlin 또는 Java로 Spring 기반의 백엔드 서비스를 개발해 본 경험이 있으면 좋아요.  
- 트랜잭션 처리·정합성 이슈를 고려한 DB 설계·운영 경험, 또는 이자 계산·금리 산출·정산 등 수치 기반 금액 흐름을 다뤄본 경험이 있다면 좋아요.  
- 복잡한 정책 로직을 구조화하고, 장애나 정책 변경 등 예외 상황에서 구조적인 대응 방안을 설계하거나 개선을 주도한 경험이 있다면 좋아요.  
- 팀 내에서 설계 기준을 수립하거나 기술적 개선을 주도한 경험이 있다면 큰 강점이에요.  
- 채권관리·사후관리·연체 시스템·마이너스통장 등 금융권 정책 기반 시스템을 경험해 본 분이라면 더욱 좋아요.
