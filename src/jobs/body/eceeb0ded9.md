### 합류하게 될 팀에 대해 알려드려요  
- 토스뱅크 Data Analytics Specialist는 서비스 단위의 스쿼드 조직에 소속되어 신뢰성 있는 분석 결과를 도출하고 데이터를 기반으로 제품을 개선해요.  
- 프로덕트, 디자인, 데이터, 엔지니어링 등 다양한 직군의 동료들이 모여 하나의 스타트업처럼 자율성을 가지고 일하고 있어요.

### 합류하시면 함께 할 업무예요  
- Data Analyst와 협업하며 도메인 내 데이터 분석 관련 업무를 서포트해요.  
- SQL을 활용해 설계한 실험과 요청 데이터를 추출·분석하고, 이해하기 쉽게 제공해요.  
- 분석에 필요한 로그가 제대로 남는지 확인하고, 협업을 통해 로깅을 고도화해요.  
- 분석에 필요한 데이터 마트를 설계하고, 정합성 높은 데이터를 추출해요.  
- 분석 결과를 시각화하거나 대시보드를 운영해요.

### 이런 분과 함께하고 싶어요  
- SQL을 능숙하게 활용해 실제 서비스/제품 데이터를 직접 추출하고, 결과의 정합성을 검증할 수 있는 분이 필요해요.  
- 대시보드 구축·운영 또는 데이터 시각화 경험이 있는 분이면 좋아요.  
- 실제 제품 환경에서 실험 데이터를 분석해본 경험이 있다면 더욱 좋아요.  
- 요청을 정확히 파악하고 원활하게 소통할 수 있는 협업 능력이 필요해요.

### 이력서는 이렇게 작성하시는 걸 추천해요  
- 제품 관련 데이터 분석 경험을 구체적으로 기술해 주세요.  
- 대시보드 구축이나 시각화 경험이 있다면 사용 도구와 함께 기술해 주세요.  
- 개인 인적사항 및 활동(학력, 대외활동, 인턴 등)에 대해서는 시기와 내용을 꼭 명확하게 기재해 주세요.
