### 합류하게 될 팀에 대해 알려드려요  
- 토스의 클라이언트 플랫폼 조직은 사용자들이 토스를 사용하는 이유인 탁월한 사용자 경험을 설계하고, 200명이 넘는 개발자들이 제품 개발에만 집중할 수 있는 환경을 구축하고 있어요.  
- 지금 클라이언트 플랫폼에서는 서비스를 만드는 과정 자체를 다시 설계하고 있어요. 요구사항 정리, 코드 작성, 테스트, 배포로 이어지는 제품 개발 과정에서 사람이 직접 해야 하는 일을 하나씩 줄여요.  
- 목표는 개발의 병목이 오로지 AI 성능이 되도록 하는 것이에요. 제품 코드 대부분이 자동으로 생성되고, 서비스 개발자는 구조 설계와 검수에 시간을 쓰는 환경을 만들어요.  
- 세 자릿수 규모의 엔지니어가 매일 업무에 사용하는 개발 워크플로우를 바꾸는 것부터 시작해서, 엔지니어는 물론이고 PO, 디자이너 등 협업하는 팀원 모두의 일하는 방식을 새로 정의해요.

### 합류하면 함께 할 업무예요  
제품 개발 워크플로우를 단계별로 쪼개고, 각 단계에서 사람이 개입해야 하는 지점을 찾아서 하나씩 제거해요.  
- 사람과 LLM이 모두 참고할 수 있는 지식 베이스 아키텍처를 설계하고, 데이터가 쌓이는 파이프라인을 구축해요.  
- 디자인에서 자동으로 코드가 생성될 수 있도록 하는 Design-to-code 번역 시스템을 만들어요.  
- 기능적으로 제품이 올바르게 동작하는지 확인할 수 있는 E2E 테스트 프레임워크와 환경을 만들어요.  
- 시각적으로 제품에 예기치 못한 변화가 없는지 확인할 수 있는 비주얼 테스트 도구를 만들어요.  
- 코드 품질을 정적으로 검사하는 린터와, 정성적으로 분석할 수 있는 LangGraph 파이프라인을 만들어요.  
- LLM이 기존 코드를 쉽게 참고해서 구현할 수 있는 의미 기반 코드 데이터베이스를 만들어요.

### 지금까진 이런 일을 했어요  
- 세 자릿수의 개발자들이 별도 설정 없이도 품질 높은 LLM 스킬과 사내 도구를 활용할 수 있도록, 자동으로 LLM 설정을 동기화하는 플랫폼 도구인 Toss Agent Preset(TAP)을 만들었어요.  
- LLM이 기존 코드베이스와 사용자 동작을 바탕으로 자동으로 E2E 테스트를 작성해서, 사람이 직접 테스트하지 않아도 올바르게 동작이 검증되는 시스템을 만들었어요.  
- 디자이너가 정의한 Figma 디자인을 결정론적으로 iOS, Android, Web, React Native 코드로 옮기는 파이프라인을 만들었어요.  
- 조직 안에 지식 베이스를 구축하고, 이를 바탕으로 사람과 LLM의 질문에 답하는 RAG 챗봇을 만들었어요.

### 이런 분과 함께하고 싶어요  
- 빌드, 테스트, CI/CD 같은 개발 인프라나 자동화 워크플로우를 직접 만들어보신 경험이 필요해요. 연구실 실험 파이프라인이나 개인 프로젝트도 좋아요.  
- 반복되는 일을 시스템으로 없애는 데 재미를 느끼시는 분이면 좋겠어요.  
- 파이프라인이 왜 느린지, 왜 깨지는지 원인까지 파고들어 본 경험이 있으면 좋겠어요.  
- 만든 걸 혼자 쓰고 끝내지 않고, 다른 사람이 쓰는 데까지 가본 경험이 있으면 좋겠어요. 연구실 동료든 오픈소스 사용자든 상관없어요

### 이런 경험이 있다면 더 좋아요  
- 프롬프트와 툴 설계, 컨텍스트 구성, 하네스, 에이전트 루프 등 LLM을 기반으로 도구나 업무 환경을 직접 만들어보셨다면 좋아요.  
- 생성된 결과물의 품질을 정량적으로 다뤄본 경험이 있으면 좋아요.  
- 무엇을 자동화할지 스스로 정하고, 그 판단이 맞았는지 데이터로 확인해본 경험이 있으면 좋아요.  
- 도구를 만드는 걸 넘어서 생산성을 높이기 위한 업무 방식이나 문화를 구축한 경험이 있으면 알려주세요.

### 이력서는 이렇게 작성하시는 걸 추천해요  
- 경험을 나열하기보다, 그 경험에서 무엇을 바꿨고 무엇을 배웠는지 적어주세요.  
- 연구실이든 개인 프로젝트든, 자동화나 툴링으로 작업 환경을 개선한 경험이 있으면 알려주세요. 개선 전후를 숫자로 적어주시면 좋아요.  
- 불편한 걸 참지 않고 직접 고쳐본 경험이 있으면 적어주세요. 실험 스크립트를 자동화했다거나, 반복되는 수작업을 도구로 만든 것도 좋아요.  
- AI를 써본 것을 넘어 AI가 동작하는 환경을 만들어보셨다면 자세히 알려주세요.
