### 합류하게 될 팀에 대해 알려드려요  
- 토스의 Internal Systems Engineer (MDM) 포지션은 Corporate It Security Team 에 속해 있어요.  
- Corporate It Security Team 은 계정, PC, SaaS 솔루션부터 네트워크, 서버, VDI, MDM까지 사내 IT 인프라를 구축하고 운영하는 팀이에요.  
- 해당 포지션은 토스의 모바일 테스트 자동화 플랫폼이 안정적으로 확장될 수 있도록, iOS/Android 테스트 기기와 디바이스팜 운영 체계를 고도화하는 역할을 맡아요.  
- 모바일 기기 등록, 앱 버전 관리, 원격 제어, 보안 정책, 물리 장비 운영까지 아우르며 토스 팀원들이 로컬 테스트 환경을 직접 세팅하지 않아도 되는 구조를 함께 만들어요.

### 합류하면 함께 할 업무예요  
- iOS/Android 모바일 기기를 MDM 기반으로 등록, 프로비저닝, 정책 적용, 앱 배포, 업데이트, 회수하는 전체 라이프사이클을 관리해요.  
- Intune, Kandji, Jamf, Workspace ONE 등 MDM 솔루션을 활용해 모바일 테스트 기기의 보안 정책, 컴플라이언스 정책, 앱 설치 정책을 설계하고 운영해요.  
- 랙, 전원, USB 허브, 네트워크, Mac mini, 모바일 기기 연결 상태 등 물리 디바이스팜 운영에 필요한 기준과 SOP를 만들어요.  
- 보안팀, QA 플랫폼, 클라이언트 플랫폼, 인프라, 네트워크 팀과 협업하여 안전하면서도 테스트 실행 속도를 늦추지 않는 모바일 기기 운영 환경을 만들어요.

### 이런 분과 함께하고 싶어요  
- MDM을 활용해 iOS/Android 모바일 기기를 엔터프라이즈 환경에서 직접 구축하고 운영한 경험이 필요해요.  
- Intune, Kandji, Jamf, Workspace ONE, MobileIron 등 하나 이상의 MDM 솔루션을 깊게 다뤄본 경험이 필요해요.  
- Wi-Fi, 유·무선 인증, VPN, Okta/Entra ID 기반의 모바일 업무 환경과 인증 흐름을 이해하고 문제를 해결할 수 있어야해요.  
- Bash, PowerShell, Python 등으로 반복적인 기기 관리 업무를 자동화하거나 운영 리포트를 만들어 본 경험이 있다면 좋아요.  
- 사용자가 편리하게 테스트를 실행할 수 있는 환경과 회사가 요구하는 보안/컴플라이언스 기준 사이의 균형을 중요하게 생각하는 분이면 좋아요.
