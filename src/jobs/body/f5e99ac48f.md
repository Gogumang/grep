**토스페이먼츠를 소개해드려요**  
- 토스페이먼츠는 사업의 어려움과 비효율을 이해하고, 기술부터 운영까지 사업에 필요한 모든 솔루션을 제공하는 것을 목표로 합니다. 소비자들에게 쉽고 편한 서비스 경험을 제공하고, 가맹점들에게는 오직 사업에만 집중할 수 있는 환경이 보장되는 제품을 만들고 있어요.  
- '전자결제 시장 혁신'을 핵심 목표로 자율과 책임의 원칙 아래, 강력한 상호 신뢰의 문화 속에서 일하고 있어요. 결제 산업의 미래를 함께 만들어 갈 동료를 기다리고 있습니다!

### 합류하게 될 팀에 대해 알려드려요  
- 토스페이먼츠의 Data Engineer는 토스페이먼츠 Data Engineering 팀에 속해있어요.  
- Data Engineering 팀은 Data Engineer와 Data Analytics Engineer로 구성되어 있어요.  
- Data Engineering 팀은 데이터의 분석, 활용 및 플랫폼 구축, 데이터 관리 (데이터 확인, 기능, 구현, 정제, 운영, 설명)의 업무를 수행해요.

### 합류하면 함께할 업무예요  
**데이터 플랫폼 구축 및 운영**  
- AWS Kubernetes 기반 데이터 플랫폼의 아키텍처 설계, 배포, 모니터링, 운영 정책 수립을 담당해요.  
- Airflow 기반 배치 파이프라인과 자체 개발 시스템으로 수천 개 규모의 작업을 관리하고, DQ/메타데이터 조회 등 개발 효율화 자동화 업무를 함께 해요.  
###  
**실시간 스트리밍 파이프라인**  
- CDC 기반으로 원천 데이터를 실시간으로 수집·처리하고, DW까지 확장하는 스트리밍 파이프라인을 설계하고 운영해요.  
- Apache Flink를 활용해 실시간 데이터 처리 로직을 개발하고, 장애 대응 및 성능 튜닝을 직접 담당해요.  
- 스트리밍 데이터를 수집·가공·적재하는 실시간 데이터 처리 전반을 다뤄요  
###  
**실시간 데이터 서빙 플랫폼**  
- 실제 서비스에서 대용량 데이터를 실시간으로 조회할 수 있는 서빙 플랫폼을 개발하고 운영해요.  
- MSA 환경에서 여러 서비스에 흩어진 데이터를 결합하고, 대량 트래픽을 지연 없이 처리하는 검색·조회 시스템을 구성해요.

### 이런 분과 함께하고 싶어요  
- 기술 원리를 스스로 파고들고, 문제 발생 시 근본 원인을 찾아 해결하는 걸 즐기는 자세가 필요해요.  
- 최소 1년 이상 Kubernetes 환경에서 데이터 플랫폼을 구축하거나 운영한 경험이 있어야 해요.  
- Apache Spark를 활용한 대용량 배치 처리 및 튜닝 경험이 필요해요.  
- CDC 또는 스트리밍 파이프라인을 직접 설계·운영해본 경험이 있어야 해요.  
- Java, Python 등을 활용한 데이터 애플리케이션 개발 역량이 있으면 좋아요.  
- RDBMS, Kafka 등 데이터 소스 기술에 대한 기본적인 이해가 있어야 해요.  
- ArgoCD 등을 활용한 데이터 플랫폼 CI/CD 운영 경험이 있다면 좋아요.  
- StarRocks, ClickHouse, Druid 등 실시간 OLAP/서빙 엔진 경험이 있다면 좋아요.  
- Apache Flink 등 스트리밍 프레임워크 실무 경험이 있다면 좋아요.  
- 다양한 이해관계자와 적극적으로 소통하며 업무를 주도적으로 이끌어가는 분이면 좋아요.

- 토스페이먼츠의 팀원과 고객은 여러 데이터를 만들고 다양하게 활용하는데요. 데이터 팀은 그런 토스페이먼츠 고객의 성공을 위해 거대한 규모의 빅데이터 처리 플랫폼을 구성하고 원하는 시점에 원하는 형태로 데이터를 제공하는 역할을 해요.

- 데이터를 온 회사에 흐르게 하는 데이터 팀은 페이먼츠의 심장과도 같은 팀이라 매일 새로운 보람을 느끼고 있어요. 토스페이먼츠에서 회사의 동력을 함께 만들 팀원들을 모시고 싶어요.
