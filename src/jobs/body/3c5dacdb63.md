### ML인프라팀을 소개해요

"더 단순하게, 더 빠르게, 하지만 안정적으로"  
당근은 수많은 프로덕트들이 한데 모여있다보니 마치 하나의 스타트업 생태계처럼 각 프로덕트들마다의 Stage와 고민이 달라요. 당근 ML 인프라팀은 이 모든 걸 연결하는 복잡성을 각 제품팀이나 개발자가 직접 감당하지 않게 하려고 해요. 당근의 모든 팀들이 ML과 LLM 기반 서비스를 만들 때, “이렇게까지 간단해도 되나?”라는 와우 포인트를 설계해요. 기술의 복잡함을 플랫폼이 대신 책임지게 만들고, 구성원들은 사용자 문제와 제품 아이디어에 더 집중할 수 있도록 해요. 이를 위해 자체 개발한 LLM 라우터, 대규모 학습 파이프라인, 그리고 실험부터 배포까지의 흐름을 연결하는 ML 메타데이터 시스템을 만들고 있어요.

### 이런 일을 해요

-   사내 프롬프트 스튜디오와 에이전트 시스템을 지원하는 LLM 라우터를 개발하고 있어요. 단순한 프록시를 넘어서, 다양한 LLM의 기능과 특성을 자연스럽게 활용할 수 있도록 추상화하고 확장하고 있어요  
-   ML 메타데이터 관리 및 조회 시스템을 자체 개발하고 있어요. 단순한 관리 도구를 넘어서 AI 에이전트 기반으로 실험과 운영을 분석하고, 자동화하는 방향으로 발전시키고 있어요  
-   여러 학습 프레임워크를 위한 머신러닝 모델 배포 시스템을 운영/개발하고 있어요. 사내 배포 시스템(Kontrol)과 긴밀하게 연동해, 누구나 쉽고 안정적으로 모델을 서빙하고 관리할 수 있는 환경을 만들고 있어요  
-   그 외에도 당근에서 머신러닝과 AI를 더 잘 활용할 수 있다면, 문제의 크기나 형태에 관계없이 필요한 모든 것을 만들어가고 있어요

### 이런 분과 함께하고 싶어요

-   당근에서 다루는 문제들은 뚜렷한 정답이나 레퍼런스가 없는 경우가 많아요. 새로운 문제를 정의하고 해결하는 과정을 즐기시는 분과 함께하고 싶어요  
-   머신러닝과 AI를 통해 더 나은 당근 서비스에 기여하고 싶은 열정적인 분을 찾고 있어요. 기술 자체보다, 실제 문제를 해결하고 사용자 가치를 만드는 데에 관심이 있는 분이면 좋아요  
-   파이썬을 주요 언어로 사용하고 있어요. 파이썬 기반의 개발 환경에 익숙하거나, 사용하는 데에 부담이 없는 분이면 잘 맞아요  
-   특정 도메인 경험보다 문제 해결 능력을 더 중요하게 생각해요. 이미 다른 영역에서 복잡한 문제를 잘 풀어오신 분이라면, ML이나 LLM이라는 새로운 분야에서도 빠르게 성장하실 수 있다고 믿어요  
-   백엔드 시스템이나 머신러닝 시스템을 개발해본 경험이 있다면, 팀에 더 빠르게 적응하실 수 있어요  
-   실무에서 약 3년 이상 문제를 풀어오신 분을 기대하고 있어요 (미드 레벨)  
-   실무에서 약 5년 이상 문제를 풀어오신 분을 기대하고 있어요 (시니어 레벨)
