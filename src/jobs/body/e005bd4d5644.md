> **현재 힐링페이퍼는 병역특례를 지원하지 않아요.** 아쉽지만 병역특례에 해당하시는 분들은 추후 별도 공고 오픈 시 지원 부탁 드려요.

### **함께할 팀을 소개해요**

* Cell은 강남언니 제품군(웹 · 앱 · 백오피스)을 하나의 디자인 언어로 잇는 힐링페이퍼의 크로스플랫폼 디자인 플랫폼이에요.  
* 우리 팀의 미션은 하나예요. 사내 개발자와 디자이너의 생산성을 끌어올리는 것. 이를 위해 디자인 시스템을 단순한 컴포넌트 '라이브러리'가 아닌, 내부 고객에게 전달하는 하나의 제품으로 바라봐요.  
* 잘 만든 컴포넌트 하나, 잘 닦인 도구 하나가 팀 동료들의 개발 속도와 제품 품질을 동시에 높일 수 있다고 믿으며 레버리지를 만들어요.  
* 합류하시면 웹 챕터에서 Cell의 웹 영역을 전담하며, 이미 있는 iOS/Android 담당자 · 디자이너들과 한 팀으로 Cell을 함께 키워가요.

### **이런 도구를 사용해요**

* **AI Tool:** Claude Code  
* **개발 언어:** TypeScript  
* **프레임워크:** React, Monorepo(Turborepo)  
* **디자인 토큰:** Style Dictionary (W3C DTCG)  
* **스타일링:** Tailwind CSS  
* **릴리스:** release-please (semver 자동화)  
* **디자인 협업:** Figma (Plugin/API)  
* **패키지 매니저:** pnpm  
* **인프라:** AWS, Kubernetes

### **앞으로 이런 일들을 하게 될 거예요**

* 웹 React 컴포넌트 라이브러리와 테마 시스템을 설계하고, 여러 개발자가 쓰기 좋은 컴포넌트 API를 만들어요.  
* 플랫폼 디자이너와 협업해 Figma의 디자인 언어를 코드와 일치시키는 파이프라인을 고도화하고, 브랜드 테마를 일관되게 관리해요.  
* AI를 통해 더 높은 품질의 디자인 시스템을 운영할 수 있게 Figma로부터 토큰·컴포넌트 자동화, 문서 자동화, 코드 생성 자동화를 다뤄요.  
* 컴포넌트 도입률을 추적·개선하고 코드 변경사항을 문서에 지속적으로 반영하며 개발 경험(DX)를 끌어올려요.  
* iOS/Android 디자인 시스템 담당자와 협업해 크로스플랫폼 일관성을 유지해요.
