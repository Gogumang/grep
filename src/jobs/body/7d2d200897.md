### 합류하게 될 팀에 대해 알려드려요  
- 토스증권의 AI Engineer 포지션은 WM Domain 소속이에요.  
- "투자의 힘을 모두에게" : 토스증권 WM Domain은 고객이 단기적인 시세 차익을 넘어 생애 주기에 맞춰 안정적으로 자산을 불려 나가는 투자 전략 플랫폼을 만들어요.  
- 소수 자산가의 전유물이었던 투자 자문을 모든 고객에게 제공하기 위해, LLM 기반 투자 AI Agent를 만들어요. 고객의 성향과 금융시장 상황을 이해하고, 각자에게 맞는 투자 판단을 돕는 AI 자문 서비스가 목표예요.  
- 기획 / 디자인 / 개발 / 운영이 한 팀으로 빠르게 실험하고 실행하는 조직이에요.

### 합류하면 함께할 업무에요  
- 투자 AI Agent를 설계하고 개발해요 — 고객의 투자 성향, 보유 자산, 시장 상황을 이해하고 개인화된 자문을 제공하는 LLM 기반 에이전트를 만들어요.  
- AI Agent 오케스트레이션을 구축하고 운영해요 — 멀티 에이전트 협업 구조, Tool Use / Function Calling, 메모리 관리, 라우터를 설계하고 대규모 사용자 환경에서 안정적으로 서빙해요.  
- 에이전트 품질을 측정하고 개선해요 — 평가(Eval) 데이터셋과 하네스를 구축하고, 비즈니스 요건에 따른 루프 엔지니어링으로 응답 품질을 지속적으로 끌어올려요.  
- 정형·비정형 금융 데이터를 AI Agent가 활용할 수 있는 형태로 검증·정제하고 데이터 파이프라인을 만들어요.  
- 금융 서비스에 요구되는 신뢰성·설명가능성·컴플라이언스를 갖춘 AI 제품을 만들기 위해 사일로의 PO·디자이너·서버 개발자, 그리고 컴플라이언스 조직과 긴밀하게 협업해요.

### 이런 분과 함께하고 싶어요  
- AI / LLM을 활용해 실제 제품을 개발하고 출시해본 경험이 필요해요.  
- LLM 애플리케이션 개발 경험이 있으신 분을 찾아요. (LLM API 활용, 컨텍스트 엔지니어링, RAG, Tool Calling / 라우터 개발 / Agent 구조 설계 등)  
- 프로덕션 환경에서 서비스를 만들고 운영해본 소프트웨어 엔지니어링 기본기를 갖추신 분이 필요해요.  
- 데모에서 멈추지 않고, 실제 사용자가 쓰는 제품의 품질을 데이터와 평가 체계로 증명해본 경험이 있으신 분이 필요해요.

### 이런 경험이 있으면 더 좋아요  
- 대규모 사용자를 대상으로 AI Agent 또는 LLM 기반 서비스를 운영해본 경험이 있으시다면 더 좋아요.  
- 에이전트 오케스트레이션, LLM Observability 등 LLM 에이전트에 필요한 미들웨어 및 인프라를 직접 구축해본 경험이 있으시다면 더 좋아요.  
- 증권사·자산운용사·로보어드바이저·핀테크 등 금융 서비스 개발 경험이나 투자에 대한 개인적인 관심이 있으시다면 더 좋아요.  
- 사용자 경험, 신뢰, 설명가능성, 컴플라이언스, 운영 안정성을 고려해 AI 제품을 개선해본 경험이 있으시다면 더 좋아요.

### 이력서는 이렇게 작성하시는 걸 추천해요  
- 개발하신 AI / LLM 제품이 어떤 문제를 풀었고, 그중 어떤 부분을 직접 설계·구현하셨는지 구체적으로 작성해 주세요.  
- 에이전트·프롬프트·RAG 등 기술 선택의 이유와 트레이드오프, 그리고 품질을 어떻게 측정하고 개선했는지가 드러나면 좋아요.  
- 프로젝트 나열보다는, 실제 사용자 지표나 비즈니스 임팩트로 이어진 경험 중심으로 작성해 주세요.
