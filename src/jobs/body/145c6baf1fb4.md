### 합류하게 될 팀에 대해 알려드려요  
- 토스뱅크의 Security Division은 Security Policy Team(보안정책팀), Privacy Protection Team(개인정보보호팀), System Security Team(시스템보안팀), Network Security Team(네트워크보안팀), Security Red Team(보안레드팀), Security Blue Team(보안블루팀), IT Service Team(IT서비스팀), Security Audit Team(보안자체감사팀)으로 구성되어 있어요.  
- 토스뱅크의 System Security Team Leader 는 토스뱅크 Security Division 내의 단말 및 시스템을 여러 외부 위협으로부터 지키기 위해 다양한 업무를 담당하며 System Security Team(시스템보안팀)을 리드하고 있어요.  
- Security Division은 안전하고 신뢰할 수 있는 토스뱅크 서비스를 만들기 위해 다양한 팀과 협업해요. 특히 System Security Team(시스템보안팀)은 시스템/단말보안 및 운영 관점에서 안전한 서비스를 만들기 위해 제품 조직과, 그리고 규제준수 및 내부통제를 위해 Legal & Compliance, Platform Engineering, Internal Audit 조직과 협업해요. 모든 팀이 공통의 목표를 위해 노력하기 때문에 협업이 매우 잘 이루어지고 있어요!

### 합류하면 함께할 업무예요  
- 토스뱅크의 고객을 보호하기 위해 단말 및 시스템 정보보안 솔루션을 운영 계획을 수립하고 팀 전체의 기술적 성장과 실행을 이끌어요.  
- 토스뱅크의 단말보안, 시스템보안 솔루션 운영 및 AI와 공급망 보안에 대한 통합적인 보안운영을 설계하고 고도화해요.  
- 시스템보안 관점의 가시성 확보와 운영 고도화를 위한 전략을 수립하고 적정하게 운영될 수 있는 환경을 만들어요.

### 이런 분과 함께하고 싶어요  
- 10년 이상 다양한 보안솔루션 운영 경험을 보유한 분이 필요해요.  
- 경력 내 3인 이상의 보안 팀을 직접 리딩하여 팀 성과를 만들어낸 경험이 있다면 더욱 좋아요.  
- 안전한 전자금융거래를 위해 조직의 단말 및 시스템 보안솔루션 운영 전략을 이해하고 운영정책으로 구현할 수 있는 분이 필요해요.  
- 보안솔루션의 동작 원리에 대해 이해가 깊고, 운영 정책에 대해서 스스로 기준을 수립하고 팀원들과 협의하여 최선의 의사결정을 이끌 수 있는 분을 찾고 있어요.  
- 반복 업무를 자동화하여 생산성을 높이고, 문제 해결을 위해 딥다이브한 경험을 갖고 있는 분을 찾고 있어요.  
- 다양한 오픈소스 활용 경험과 AI를 업무에 적극적으로 활용이 가능한 분과 함께하고 싶어요.  
- Bash, Python 등 스크립트 개발 경험 및 시스템간 연계를 위한 API 사용 경험이 있는 분이 필요해요.

### 이력서에는 아래 내용을 꼭 포함해 주세요  
- 자유양식의 이력서와 함께 포트폴리오를 제출해 주시는 걸 추천해요.  
- 해당 업무 영역의 경험 및 지식을 기반으로 작성해주시는 것을 추천해요.  
- 맡아온 업무를 단순히 나열하기보다, 어떤 문제를 어떻게 해결했는지 구체적인 맥락과 결과 중심으로 작성해 주세요.  
- 리더십 경험은 별도로 상세하게 기술해 주세요. 팀 규모, 운영 방식, 본인의 역할과 기여, 팀이 만들어낸 성과를 구체적으로 담아주시면 좋아요.  
- 조직 전체에 영향을 미친 보안 전략 수립이나 제도 개선 경험이 있다면 반드시 포함해 주세요.  
- 기술적 깊이를 보여줄 수 있는 사례 (직접 설계한 아키텍처, 문제 해결 과정, 자동화 결과물 등)을 함께 첨부해 주시면 더욱 좋아요.
