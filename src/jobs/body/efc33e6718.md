### 합류하게 될 팀에 대해 알려드려요  
 - Data Platform Tribe 산하 Governance Team은 토스 전사의 데이터를 안전하고 추적 가능하며 신뢰할 수 있는 상태로 만드는 팀이에요.  
 - 다양한 데이터 플랫폼과 서비스에서 운영되는 접근 권한, Lineage, 민감 정보 관리 체계를 전사 관점에서 연결하고 확장해요.  
 - 관련 팀과 함께 관리 기준을 설계하고, 이를 플랫폼과 운영 체계에 반영해 지속적으로 발전시켜요.

 # 합류하면 함께할 업무예요  
- 데이터 계보(Lineage)를 수집·구축해서 파이프라인 변경이 어디까지 영향을 주는지 추적할 수 있게 만들어요.  
- 민감 데이터 분류(Classification) 체계를 설계하고, 탐지·마스킹·보존·삭제 파이프라인을 구축해요.  
- 데이터 사용 현황과 리텐션 정책을 메타데이터로 체계화하고, 보존·정리를 시스템적으로 처리해요.  
- 전사 Feature의 등록·분류·폐기 기준을 설계하고, 검증된 Feature로 승격시키는 거버넌스 체계를 만들어요.  
- Kafka 토픽의 스키마 관리, 접근 제어, 리텐션 정책을 체계화하고, 이벤트 데이터의 품질과 계보를 추적할 수 있게 만들어요.  
- 전사 데이터 자산 현황을 메타데이터로 관리하고, 규제 대응에 필요한 감사 로그와 증적의 수집·관리를 체계화해요.  
- AI 에이전트가 사내 데이터에 접근하는 전용 권한 체계와 메타데이터 인터페이스를 만들고, 에이전트가 언제 어떤 데이터를 썼는지 감사 가능한 형태로 남겨요.

 # 이런 분과 함께하고 싶어요  
- 데이터 파이프라인(Spark, Airflow, Kafka 등)의 구조를 이해하고 직접 개발해 본 경험이 있는 분이 필요해요.  
- 데이터 접근 제어 시스템을 설계하거나 운영해 본 경험이 있는 분이 필요해요.  
- 데이터 계보(Lineage)나 메타데이터 관리 체계를 설계해 본 경험이 있으면 좋아요.  
- Feature Store나 Kafka 스키마 레지스트리를 운영하거나 거버넌스 체계를 설계해 본 경험이 있으면 좋아요.  
- LLM·에이전트를 실제 운영 시스템에 붙여 본 경험이 있으면 좋아요. 모델의 판단을 어디까지 믿고 어디서 사람에게 넘길지, 그 경계를 설계해 본 경험이면 더 좋아요.
