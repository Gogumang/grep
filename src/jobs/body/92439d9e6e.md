### 합류하게 될 팀에 대해 알려드려요  
- 토스는 호주를 시작으로 유럽, 그리고 이외 여러 국가로 글로벌 서비스를 빠르게 확장하고 있어요. 글로벌 데이터 플랫폼은 어느 한 팀이 아니라, 여러 팀의 엔지니어가 모인 Global Data Platform 길드가 팀 경계를 넘어 긴밀하게 협업하며 함께 만들어가요.  
- 합류하시면 StarRocks 클러스터 운영과 CDC를 포함한 실시간 데이터 입수를 담당하는 Data Online Processing Team 소속으로, 길드의 일원이 되어 글로벌 데이터 플랫폼 전체를 함께 만들어요.  
- 새로운 국가가 추가될 때 며칠 안에 전체 데이터 스택이 복제되는 것을 목표로, 확장에 강한 데이터 플랫폼을 지향해요.

### 합류하면 함께 할 업무에요  
- 호주·유럽을 비롯한 여러 리전의 글로벌 데이터 플랫폼을 AWS 멀티계정 환경에서 인프라부터 파이프라인까지 end-to-end로 설계하고 운영해요.  
- 싱가폴 허브에서 각 국가 리전의 데이터 플랫폼을 코드로 선언적으로 관리하고, 신규 국가 런칭 시 Terraform 기반 IaC로 EKS·Kafka·네트워크 등 데이터 인프라를 구축하며 ArgoCD·Vault 기반 GitOps 스택을 새 리전에 빠르게 복제해요.  
- Kafka, Kafka Connect(CDC), Flink 기반 스트리밍 파이프라인을 구축하고 리전으로 확장하며, 허브와 리전 간 Kafka 토픽 미러링 체계를 운영해요.  
- Airflow, dbt, Snowflake 기반 DW 배치 파이프라인을 설계·운영하고, 다국가 타임존·스키마 정책 등 글로벌 데이터 표준을 만들어요.  
- 데이터 입수 요청 접수부터 리전 반영까지 사람 손을 거치지 않는 입수 자동화 체계를 만들고, 데이터 조직의 생산성을 높이는 내부 도구를 직접 개발해요.  
- 리전별 관측성 스택을 구축하고, PII 접근통제·GDPR 리텐션 등 글로벌 데이터 거버넌스를 시스템으로 풀어가요.

### 이런 분과 함께하고 싶어요  
- 데이터 플랫폼 또는 데이터 엔지니어링 경력 5년 이상, 혹은 그에 준하는 역량으로 인프라와 파이프라인 양쪽을 모두 다뤄본 분이 필요해요.  
- AWS 기반 클라우드 환경에서 서비스를 개발하거나 운영해본 경험이 필요해요.  
- Kubernetes 환경에서 Terraform 등 IaC 도구로 인프라를 구축·운영해본 경험이 필요해요.  
- Airflow 등 워크플로 오케스트레이터 기반 배치 파이프라인 개발·운영 경험과 Data Warehouse·Mart에 대한 이해가 필요해요.  
- Snowflake 등 클라우드 데이터 웨어하우스를 사용해본 경험이 필요해요.  
- Kafka 기반 데이터 파이프라인을 직접 구축·운영해본 경험이 필요해요.  
- Python 개발 역량을 갖추고, Git 중심의 코드 리뷰와 CI/CD 워크플로가 익숙한 분이 필요해요.  
- 장애가 발생했을 때 근본 원인을 추적하고, backfill과 재발 방지까지 스스로 완결해본 경험이 필요해요.
