### 토스증권 서버 챕터를 소개해요  
- 무언가를 함께 만들어내서, 보다 나은 가치를 만들고자 하는 동료들이 정말 많아요.  
- 아이디어를 냈을 때 "이래서 안 돼요", "이미 잘 되고 있는데 굳이 바꿔야 할까요?"라고 하기보다, "이렇게 하면 해낼 수 있겠네요"라고 생각하는 분들이요. 어떤 의견이든 서슴없이 말할 수 있고, 누구도 비난하거나 질책하지 않고 끝까지 경청하며, 함께 방법을 찾아가는 챕터예요.  
- 작게는 코드 리뷰부터 크게는 엔지니어링 데이, 서버 챕터 위클리까지, 서버 개발자들이 팀을 넘어 협업할 수 있도록 받쳐주는 커뮤니티가 있어요.  
- 다양한 사일로/팀 소속으로 업무하고 있어요.

### **이번 Server Developer 집중 채용에서 지원 가능한 포지션을 안내드려요**  
###  
###  
###  
>1️⃣ **Server Developer (Product)**  
###  
###  
###  
- Server Developer (Product)는 Product Owner, Product Designer, Frontend Developer, Server Developer, Data Analyst 등 여러 직군이 작은 스타트업처럼 자율성을 가지고 제품을 만드는 '사일로'에서 일해요.  
- 토스 증권에서는 서버 개발 환경으로 Java/Kotlin, Spring Framework를 주로 사용하고 있어요.  
- 다양한 라이브러리와 개발 방식 중에서 합리적이고 효율적인 방식을 찾아 선택하고 공통화시키는 작업을 해요. 전체적인 관점에서 좋은 아키텍처에 대한 고민을 하고 개선해 나가요.  
- Java/Kotlin, Spring Framework를 기본으로 Redis, Kafka, Kubernetes, ELK를 적극적으로 사용하며, 대용량 트래픽이나 동시성 처리에 대한 고민을 많이 하시게 될 거예요.

>2️⃣ **Server Developer (Japan Product)**  
###  
###  
###  
- Server Developer (Japan Product)은 'Global Team'에 속해 업무해요. Global Team은 일본 시장에서 현지 사용자를 위한 새로운 디지털 금융 경험을 만들고 있어요.  
- 서비스 지표와 사용 데이터를 바탕으로 제품을 빠르게 개선하고, 일본 사용자의 특성과 현지 환경에 맞게 기능과 데이터 흐름을 고도화해요.  
- 서버 제품을 중심으로 일하되, 필요하면 데이터 파이프라인과 운영 기반까지 직접 개선해요. 전문성이 필요한 영역은 Data Engineer, ML Engineer, Platform Engineer와 함께 설계해요.  
- 리전 간 서비스/데이터 경계를 고려해 API, 데이터 모델과 이벤트 기반 파이프라인을 설계하고, 외부 데이터 벤더와 사내 여러 플랫폼을 안정적으로 연결해요.

>3️⃣ **Server Developer (Platform)**  
###  
###  
###  
- Server Developer (Platform)는 '서버 플랫폼팀'에 속해 일해요. 서버 플랫폼팀의 목표는 증권 서비스들이 더 쉽고 빠르게 런칭되고 안정적으로 운영되도록 만드는 거예요.  
- 다른 개발자들이 불편한 것들을 모아서 공통화하고, 요구사항을 모아 새로운 기능을 추가하고, 여러 영역에 걸쳐 발생하는 문제를 해결하는 역할을 하고 있어요.  
- 서버 개발 환경으로 Java/Kotlin, Spring Framework를 많이 사용하고 있어요. 따라서 관련된 작업들을 많이 하게 되는데요, 다양한 라이브러리와 개발 방식 중에서 합리적이고 효율적인 방식을 찾아 선택하고 공통화시키는 작업을 해요.  
- 성능 개선을 위해 여러 프로파일링 툴을 다루고, 성능 개선을 어떻게 할지 고민해보고, 실제 action item 들을 뽑아내곤 해요. 또한, 전체적인 관점에서 좋은 아키텍처에 대한 고민을 하고 개선해 나가는 작업을 담당해요.

>4️⃣ **Server Developer (Market Platform)**  
###  
###  
###  
- Server Developer (Market Platform)은 시세팀에 속해 '토스증권 시세 플랫폼'을 개발해요. 시세팀은 국내주식과 해외주식 시세 제공 등 증권 서비스에 필요한 다양한 업무를 수행하고 있어요.  
- 시세 데이터의 책임자이자 개발자로서 어떤 기능들이 필요할지 직접 고민하고 의견을 수집해 방향성을 정하고 만들어 나가고 있어요.  
- 대고객 API/WebSocket부터 대외기관 통신까지 넓은 영역을 개발하고, 시간 대용량 트래픽과 저지연 이벤트 처리를 경험하며, 까다로운 문제들을 자주 접할 수 있어요.  
- 전체적인 관점에서 좋은 아키텍처를 고민하고 개선해 나가요. 배포하기 쉬운 구조, 운영하기 쉬운 구조, 안정성을 위한 구조, 성능 개선을 위한 구조를 고민하고 실행에 옮겨요.

>5️⃣ **SRE**  
###  
###  
###  
- Site Reliability Engineer는 Server Chapter 소속으로, SRE Team에 속해 업무해요. SRE Team은 서비스의 높은 신뢰성과 안정성을 책임져요.  
- 대규모 트래픽 환경에서 이상 징후를 사전에 감지하고 빠르게 대응할 수 있도록 효과적인 모니터링 시스템을 설계하고 운영해요.  
- 장애 발생 시 누구보다 빠르게 대응하고, 서비스 영향도를 최소화하기 위한 대응 프로세스를 설계하고 운영해요.  
- 인프라, 네트워크, Kubernetes 환경 전반의 가시성을 확보하고, 이를 실제 서비스 지표와 유기적으로 연결할 수 있는 환경을 구축해요.  
- 서비스 장애 발생 시 로그 분석에 그치지 않고, eBPF, 메모리, 네트워크, 커널 영역까지 폭넓게 분석해 복합적인 원인을 찾아내요.

>6️⃣ **Server Developer (FEP)**  
###  
###  
###  
- Server Developer(FEP)는 FEP Team에 소속되며, 주문/대외FEP, 대내외 파일 송수신, 내부 시스템 연계 및 모니터링 등 대외접속 관련 플랫폼의 개발 및 운영 업무를 담당해요.  
- FEP 시스템에 대한 개발 및 운영, 개선 업무를 수행하고 있어요.  
- 대외기관과 주로 TCP/IP를 사용하므로 기본적으로 소켓 프로그래밍을 사용하고, 데이터 송수신 및 저장, 분배를 위해 다양한 기법을 사용해요.  
- 각종 대외기관과의 연동을 진행해야 하므로 각 기관별 특성을 파악하고, 프로토콜을 이해하고, 발생할 수 있는 상황들에 선제적으로 대응할 수 있도록 다양한 준비를 해요.
