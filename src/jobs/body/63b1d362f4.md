### 합류하게 될 팀에 대해 알려드려요  
 - 토스뱅크의 DevOps 팀은 Server Platform Division에 속해 있어요.  
- Server Platform Division은 제품 개발자가 제품 개발에만 집중할 수 있도록, 서버 개발과 관련된 공용 시스템을 책임져요.  
- DevOps 팀은 그 중에서 Kubernetes 클러스터를 운영하는 등 프로그래밍 이외의 일을 주로 맡고 있어요.

 # 합류하면 함께할 업무예요  
 - Kubernetes와 Istio를 기반으로 서비스 클러스터를 운영해요.  
- 빌드/배포 시스템을 운영하고 반복 작업을 자동화하여 개발 생산성을 높여요.  
- 모니터링 시스템을 운영하고 고가용성 아키텍처를 구현하여 서비스 안정성을 높여요.  
- 업무 과정에서 보안과 규제를 준수할 수 있는 시스템을 만들어요.

 # 이런 분과 함께하고 싶어요  
- Container orchestration 기술을 바탕으로 서비스를 운영해보신 분을 원해요.  
- 빌드/배포 시스템이나 모니터링 시스템을 큰 규모에서 운영하고 개선해보신 분을 원해요.  
- 보안과 규제 준수에 대한 이해도가 있으신 분을 원해요.  
- “문제 정의 - 대안 도출 - 비교 검증 - 점진 적용 - 추가 개선“의 모든 과정을 스스로 수행해보신 분을 원해요.

 # 이런 분이면 더 좋아요  
- Kubernetes와 Istio를 활용해서 서비스를 운영해보셨으면 더 좋아요.  
- On-premise 환경에서 서비스를 운영해보셨으면 더 좋아요.

 # 이력서는 이렇게 작성하시는 걸 추천해요  
 - 주로 활용하신 기술을 알 수 있게 적어주시면 좋아요.  
 - 어떤 문제를 어떻게 해결해서 어떤 결과를 얻었는지 적어주시면 좋아요.  
 - 기술적 의사 결정이 필요했던 일이 있다면 그 과정이 드러나게 적어주시면 좋아요.

 - 토스뱅크 내부규정상 결격사유 해당자 또는 금융기관 인력 채용 상 결격사유 해당자는 채용이 취소될 수 있어요.
