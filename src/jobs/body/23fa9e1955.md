### 합류하게 될 팀에 대해 알려드려요  
- Node.js Developer는 토스애즈의 광고 제품을 데이터로 완성하는 **광고 데이터 플랫폼**을 만드는 팀에 합류하게 돼요.  
- 커머스, 앱스토어 등 외부 생태계의 데이터를 토스 광고 제품과 연결하는 데이터 파이프라인을 함께 개발하고 운영해요. 광고 제품의 품질을 결정하는 핵심 인프라를 직접 만들어요.  
- LLM이 사이트별 연동 로직을 스스로 생성하고, 실패를 감지하면 스스로 복구하는 self-healing 파이프라인처럼 기술적으로 새로운 시도를 적극적으로 해요.  
- 새로운 시스템을 구축할 때, 많은 팀 구성원이 모여 코드 리뷰를 해요. 버그나 네이밍 미스, 컴포넌트 설계에 어색한 부분은 없는지 함께 리뷰하고 코드의 질적 향상에 대해 끊임없이 토론해요.  
- 일주일에 한번씩 엔지니어링 데이를 해요. 다양한 계열사에서 얻은 기술적인 지식들을 공유받고, 공유할 수 있어요.

### 합류하면 함께할 업무예요  
- 토스애즈 카탈로그 광고에 필요한 상품 데이터 파이프라인을 설계하고 개발해요. 다양한 외부 데이터를 정규화·검증해 광고 지면에 안정적으로 공급해요.  
- LLM 기반으로 사이트별 연동 로직을 자동 생성·배포·복구하는 시스템을 만들어요. 사람이 개입하지 않아도 파이프라인이 스스로 유지되는 구조를 지향해요.  
- 수백만 건 규모의 대량 배치를 운영해요. 트래픽 제어, 에러 분류, SLA 관리, 모니터링까지 대규모 데이터 처리의 전 과정을 다뤄요.  
- 앱스토어 연동 기반 광고 제품 등 새로운 광고 데이터 제품을 만들어요. 요구사항을 분석하고 최적의 연동 방안을 직접 설계해요.  
- 커머스 플랫폼(호스팅사, 앱스토어 등)과의 연동을 개발해요. 브라우저 자동화, Electron 기반 클라이언트 등 소스 특성에 맞는 다양한 연동 방식을 활용해요.  
- OOP와 FP 기반의 높은 코드 품질과 충분한 테스트 커버리지를 갖춘 프로젝트를 운영하며, 기능 추가와 유지보수가 쉬운 코드를 지향해요.

- 대량 배치 처리, 큐 기반 아키텍처 등 안정적인 백엔드 시스템을 운영하고, 장애 상황에서도 서비스가 중단되지 않도록 모니터링하고 대응해 본 경험이 있으신 분을 찾고 있어요.
