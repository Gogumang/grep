### 합류하게 될 팀에 대해 알려드려요  
- Data Governance Team 은 Data Platform Tribe 에 소속되어서 토스의 모든 구성원이 데이터를 빠르고, 안전하고, 올바르게 활용할 수 있도록 정책을 정하고 시스템을 만들어서 운영합니다.  
- Data Manager (Governance)는 데이터 직군이에요. 법무나 보안 조직이 규제를 법의 언어로 읽는다면, 이 사람은 같은 규제를 데이터의 언어로 읽어요. 우리 플랫폼에 어떤 데이터가 어디에 있고, 어떻게 흘러가고, 누가 쓰고 있는지를 알기 때문에 — "이 규제를 지키려면 우리 시스템에서 무엇을 바꿔야 하는지"를 가장 정확하게 말할 수 있는 사람이어야 해요. 토스 데이터 거버넌스의 다음 단계를 직접 설계하고 이끌어갈 포지션이에요.

### 아마도 이런 여정을 걸어오신 분일 거예요  
- 데이터 플랫폼, 데이터 엔지니어링, 데이터 아키텍처, 데이터 분석 등 데이터 직군에서 커리어를 쌓아오면서  권한, 민감정보, 데이터 품질과 표준, 라이프사이클 같은 문제를 풀다가 자연스럽게 거버넌스가 본업이 되신 분일 거예요.  
- 혹은 데이터 거버넌스·데이터 관리(Data Management)를 처음부터 전문으로 하되, 정책 문서가 아니라 메타데이터와 시스템, SQL로 일해오신 분일 수도 있고요.

### 합류하면 함께 할 업무에요  
- 전사 데이터 거버넌스·컴플라이언스 프로젝트를 기획하고, 데이터 엔지니어와 한 팀이 되어 끝까지 실행해요. 문서로 존재하는 정책이 아니라, 시스템으로 동작하는 정책을 지향해요.  
- 토스의 데이터 자산을 가장 깊이 이해하는 사람이 되어요. 어떤 데이터가 어디에 존재하고, 무엇이 민감한지, 어떻게 흐르는지를 메타데이터와 데이터 분류 체계로 구조화하고 — 그 위에서 정책이 자동으로 따라오는 거버넌스를 설계해요.  
- 데이터 접근 권한 관리 체계를 다음 단계로 진화시켜요. 조직과 데이터가 빠르게 늘어나는 환경에서도 최소 권한 원칙이 자연스럽게 지켜지도록, 권한의 부여·회수·모니터링 전반을 더 정교하고 자동화된 구조로 발전시켜요.  
- 데이터 리텐션(보존·파기) 거버넌스를 리딩해요. 법령상 보존 의무와 서비스 활용 요구 사이에서 데이터별 보존 기준을 지속적으로 재정의하고, 라이프사이클 정책이 플랫폼 전반에 일관되게 적용되도록 만들어요.  
- 개인정보 보호법, 신용정보법, 전자금융감독규정 등 데이터 관련 법령·규제를 데이터 플랫폼의 언어로 번역해요. 신규 서비스나 데이터 파이프라인이 만들어질 때 어떤 데이터를 어디까지 쓸 수 있는지 기준을 제시하고, 정보보호·법무·컴플라이언스 조직에는 데이터 관점의 해석을 제공하는 파트너가 되어요.  
- 가명처리·비식별화 기준을 발전시키고, 데이터 분석·ML·AI 활용이 안전하게 확장될 수 있는 환경을 만들어요. AI가 데이터를 학습하고 소비하는 시대에 맞는 새로운 거버넌스 기준을 함께 고민해요.  
- 감독당국 검사, 내·외부 감사 등 규제 대응에서 데이터 관점의 근거와 증적을 책임지고, 대응이 반복 가능한 프로세스가 되도록 함께 만들어가요.

### 이런 분과 함께하고 싶어요  
- 데이터 거버넌스, 데이터 관리(Data Management), 데이터 플랫폼·엔지니어링 등 데이터 관련 분야에서 7년 이상의 실무 경험이 있으신 분을 찾고 있어요.  
- 데이터 웨어하우스, 파이프라인, 권한 체계, 메타데이터 등 데이터 플랫폼의 구조를 이해하고, 엔지니어와 같은 언어로 대화하며 정책의 시스템화를 이끌 수 있어야 해요.  
- SQL로 데이터 현황을 직접 파악하고 검증하는 것이 자연스러운 업무 방식이어야 해요.  
- 개인정보 보호법, 신용정보법 등 데이터 관련 법령을 데이터의 관점에서 해석하고 — 이를 실제 데이터 정책과 시스템 요구사항으로 구체화해본 경험이 있어야 해요.  
- 전사 단위의 데이터 거버넌스·컴플라이언스 프로젝트를 직접 기획하고, 여러 이해관계자(엔지니어, 법무, 보안, 사업부서)를 조율하며 끝까지 실행해 성과를 만들어본 경험이 있어야 해요.  
- 복잡한 규제와 기술 사이에서 문제를 스스로 정의하고, '되는 방법'을 찾아내는 주도성이 있는 분을 찾고 있어요.

### 이런 경험이 있다면 더 좋아요  
- 금융회사, 핀테크 등 규제 산업에서 데이터 거버넌스 또는 개인(신용)정보 데이터 관리 업무를 수행해본 경험  
- 망분리 환경 등 금융권 특유의 제약 조건 아래에서 데이터 활용 체계를 설계해본 경험  
- 데이터 카탈로그, 메타데이터 관리, 데이터 리니지 도구를 도입하거나 운영해본 경험  
- 가명정보 처리, 데이터 결합(데이터전문기관), 비식별화 실무 경험  
- LLM·AI 시대의 데이터 거버넌스(AI 학습 데이터 관리, 접근 통제, 프라이버시)에 대한 고민과 실행 경험
