**핀테크 프론트엔드 개발자 (결제)** 는 서비스를 이용하는 고객들이 더 행복하고 편리한 쇼핑 경험을 누릴 수 있도록 결제 서비스와 다양한 핀테크 경험을 설계하고 운영하는 핀테크 조직에 속해 업무를 수행합니다. 간편 결제를 넘어 혁신적인 금융 경험을 만들어가는 의미 있는 여정에 함께하며, 기술을 통해 비즈니스의 가치를 극대화하고 고객의 일상을 편리하게 바꾸는 미션을 공유합니다.

### 담당 업무

* 컬리페이 서비스 웹 프론트엔드 개발/운영  
* AML(자금세탁방지) 시스템의 프론트엔드 개발/운영  
* 결제 SDK 및 서드파티 연동 페이지 개발/운영  
* AI를 활용한 신기술 및 업무효율을 위한 개발

### 자격 요건

### **\[경험\]**

* 3년 이상 프론트엔드 개발 경력을 가졌거나, 이에 준하는 실력을 가진 분  
* React, Angular, Vue와 같은 SPA 프레임워크 기반 개발 실무 경험이 있으신 분  
* 반복되는 업무·코드·장애 요소를 스스로 인지하고, 자동화 도구·공통 모듈·개발 프로세스 개선 등으로 구조적으로 해결한 경험  
* 외부 결제/금융 솔루션 연동 및 API 통합 개발 능력

### **\[지식\]**

* TypeScript 및 React 생태계에 대한 깊이 있는 이해

* 프론트엔드 보안(XSS, CSRF, CSP, 시큐어 코딩 원칙)에 대한 깊이 있는 이해  
* 앱 내 웹뷰(WebView) 환경에서의 프론트엔드 개발 특성에 대한 이해  
* 정보보안 관련 기본 지식

### **\[스킬\]**

* TypeScript, React 기반 대규모 서비스 개발 능력  
* Nx / Turborepo 등 모노레포 환경에서의 빌드·의존성 관리 능력  
* AWS Docker, Kubernetes 등 컨테이너 환경 핵심 서비스의 숙련된 활용 능력  
* MSA 환경에서의 서비스 개발, 배포 자동화, 모니터링 및 트러블슈팅 능력  
* Git Flow 등 버전 관리 시스템을 활용한 효율적인 코드 관리 능력
