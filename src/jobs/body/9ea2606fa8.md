### 합류하게 될 팀에 대해 알려드려요  
- 토스증권 Data Engineer(금융데이터/재무)는 AI Info & Data Silo 소속이에요. AI Info & Data Silo는 뉴스, 공시, 실적, 시세 등 증권 도메인의 방대한 데이터를 모으고 다듬어, 투자자에게 필요한 정보를 제공하는 AI 기반 데이터 서비스를 만드는 팀이에요. 이를 위해 LLM 기반 기술과 자체 데이터 플랫폼을 활용하고 있어요.  
- 글로벌·국내 금융 데이터 벤더와 DART·KIND·SEC 같은 공시 원천에서 제공하는 다양한 투자정보를 다루며, 국내 서비스 확장과 글로벌 비즈니스 성장에 발맞춰 여러 국가의 금융 데이터를 확장성 있고 안정적으로 다룰 수 있는 구조를 만들어가고 있어요.

### 합류하면 함께 할 업무예요  
- 국내외 공시·실적·경제지표·시세 등 다양한 도메인의 데이터를 수집·가공·적재하는 파이프라인을 구축하고, 장애 대응·백필·모니터링 등 운영 전반을 담당해요.  
- 공시 등 원천 비정형 데이터를 LLM으로 구조화해 투자 정보 자산으로 만들고, 지속적으로 새로운 기술 시도를 이어가요  
- Refinitiv(LSEG), S&P Global, FnGuide 등 외부 벤더의 데이터 명세를 분석해 사내 표준 데이터 모델로 매핑하고, 복수 벤더 간 데이터 격차를 조정하는 기준을 수립해요.  
- 벤더별로 다른 종목 식별자(티커, ISIN, RIC 등)를 사내 표준 식별자와 매핑하고, 티커 변경·상장폐지·기업 액션 등 다양한 이벤트를 대응하며 데이터를 관리해요.  
- 재무·가격 데이터 기반의 퀀트 팩터 산출 파이프라인을 개발하고, 산출 로직의 정확성을 검증해요  
- 대용량 투자정보를 탐색·분석해 이상값과 식별자 매핑 오류를 탐지하고, 원천 데이터와 가공 데이터 사이의 정합성·완전성·적시성을 검증하는 품질 체계를 구축해요

### 이런 분과 함께하고 싶어요  
- 3년 이상의 데이터 엔지니어링 실무 경험이 있으신 분, 금융 데이터 처리 경험이 있다면 더 좋아요.  
- Python, SQL 기반의 데이터 수집·가공 역량이 필요해요.  
- 외부 API 및 파일 연계 기반 수집 시스템을 직접 설계·구현해본 경험이 필요해요.  
- Airflow 등 배치 파이프라인을 개발·운영해본 경험이 필요해요.  
- RDBMS 및 분산 데이터 환경(Impala, ClickHouse, Kafka 등)에서 데이터를 처리해본 경험이 필요해요.  
- 금융 데이터 도메인에 대한 이해를 바탕으로, 복잡한 원천 데이터를 유의미한 투자 정보 자산으로 가공해본 경험이 필요해요.  
- 데이터 정합성·품질 문제를 단순 오류 수정에 그치지 않고, 데이터 구조와 도메인 맥락 관점에서 원인을 추적해 근본적으로 해결해본 경험이 필요해요.

- 복수 금융 벤더의 데이터를 비교·통합하거나, 이를 금융 서비스에서 활용할 수 있도록 설계해본 경험이 있으면 더 좋아요.  
- Kotlin, Java 등 JVM 계열 언어로 서비스를 개발해본 경험이 있으면 더 좋아요.  
- Kubernetes 환경에서 서비스를 배포·운영해본 경험이 있으면 더 좋아요.  
- LLM 등 AI 기술로 비정형 공시 데이터를 구조화하는 파이프라인을 실무에 적용해본 경험이 있으면 더 좋아요.  
- 재무·시세 데이터 기반의 투자 지표(퀀트 팩터) 계산 로직을 파이프라인으로 구현해본 경험이 있으면 더 좋아요.  
- Claude Code, Cursor 등 AI 개발 도구를 개발·운영 워크플로우에 통합해 활용해보신 분이면 더 좋아요.
