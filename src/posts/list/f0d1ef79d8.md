NHN Cloud Relational Database Service for SQL Server (RDS for MS-SQL)는 Microsoft SQL Server를 클라우드 환경에서 제공하는 서비스입니다.  복잡한 설정 없이 고가용성의 Microsoft SQL Server를 사용할 수 있습니다.  이 글에서는 어떻게 고가용성을 제공하는지에 대해서 간략하게 소개하고 있습니다.
