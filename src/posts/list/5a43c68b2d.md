이 이미지는 생성형 AI를 활용해 제작하였습니다. 안녕하세요, NOL QA팀입니다! 지난번 포스트맨에서 젠킨스까지: QA 팀의 API 테스트 자동화, 파란만장 성장기 에서 Postman과 Jenkins로 API 테스트 자동화를 구축하며 겪었던 파란만장한 여정, 다들 기억하시나요? 😉 오늘은 바로 그 후속편!
