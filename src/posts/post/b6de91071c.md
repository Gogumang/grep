안녕하세요. NHN엔터테인먼트 김태경 입니다.

유니티를 사용하다보면 가끔 유니티 에디터 상에서 스크립트 아이콘이 들어가 있는걸 발견하곤 하는데요.아래와 같이 말이죠.

![1.png](https://images.gogumang.com/b6de91071c/02.png) 예) EventSystem

위 스크립트처럼 유저 스크립트에도 아이콘을 변경하는 방법에 대해서 간단하게 알아보겠습니다.

**1. Inspector Debug 모드를 이용한 수정**

1. Inspector 윈도우 디버그 모드 설정 Inspector 윈도우의 아래 아이콘을 클릭해서 Inspector 윈도우를 디버그 모드로 변경합니다. ![2.png](https://images.gogumang.com/b6de91071c/03.png)

\[참고\] Inspector의 Debug 모드에선 Normal 모드에선 노출되지 않는 Private 변수들이 Inspector를 통해 노출되므로 에디터에서 Private 변수들을 쉽게 추적 할 수 있습니다.

2. 원하는 유저 스크립트 선택 유저 스크립트를 Project 윈도우를 통해 선택합니다. 그럼 기존과는 다른 설정 항목들을 볼 수 있습니다.

![3.png](https://images.gogumang.com/b6de91071c/04.png)

3. 아이콘 텍스처 설정 이제 원하는 아이콘 텍스처를 Icon 항목에 드래그 해주시면 됩니다. ![4.png](https://images.gogumang.com/b6de91071c/05.png)

4. 유저 스크립트 확인 해당 스크립트가 추가된 게임오브젝트를 확인해보시면 아이콘이 적용된 것을 확인할 수 있습니다. ![5.png](https://images.gogumang.com/b6de91071c/06.png)

**2. Inspector의 아이콘을 이용한 수정** 아래 스크립트 아이콘을 클릭해서 Other메뉴를 눌러도 간단하게 아이콘을 바꿀수 있습니다 :D

![6.png](https://images.gogumang.com/b6de91071c/07.png)

**\[주의\]** 두 수정 방법에는 메타데이터를 쓰는 방법에 차이가 있습니다. 1번 방법의 경우 메타데이터의 Icon 항목이 File 정보로 덮어써지지 않으므로 Package Export를 할 경우, 아이콘 정보가 같이 나가지 않습니다. 2번 방법을 사용할 경우, 메타데이터의 Icon 항목에 텍스처의 파일 정보가 같이 입력되므로 Package Export시 아이콘 정보가 함께 나가 아이콘 정보를 유지할 수 있습니다. (Export할 때, 아이콘 텍스처도 함께 내보내야 합니다)
