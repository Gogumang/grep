얼굴 인식(Face Recognition) 기술은 컴퓨터 비전(Computer Vision)의 주요 분야로 기계학습(Machine Learning)을 이용해 시스템에 입력된 이미지 속 인물이 내부 데이터베이스(DB)에 미리 저장된 인물 중 누구와 가장 유사한지를 식별(Identification)하거나, 시스템에 입력된 이미지 속 두 인물이 동일인인지를 검증(Verification)하는 서비스입니다. 최근 인공지능(AI), 사물인터넷(IoT) 기술과 결합하면서 다양한 분야에서의 활용도가 높아지며 주목받고 있는 기술입니다.

## 주요 기능

* 모든 기능은 UI 없이 REST API 형식으로 제공됩니다.
* 단, '얼굴 감지', '얼굴 비교'는 console에서 직접 사진을 넣고 결과를 볼 수 있습니다.

### 얼굴 감지 및 분석

이미지에서 얼굴을 감지하고 분석해서 얼굴, 눈, 코, 입의 위치정보를 찾아줍니다. 찾은 얼굴에서 특징을 추출하여 그룹에 저장해 놓고 얼굴 검색에 사용할 수 있습니다.

![1.png](https://images.gogumang.com/ba114570ce/01.png)

### 얼굴 비교

두 개의 이미지에서 각각 얼굴들을 감지하고 비교합니다. 첫 번째 이미지에서 감지된 가장 큰 얼굴과 두 번째 이미지에서 감지된 얼굴들을 비교하고 얼마나 유사한지 수치화한 유사도 값으로 정렬하여, 얼굴의 위치정보와 함께 반환해 줍니다.

![2.png](https://images.gogumang.com/ba114570ce/02.png)

### 그룹 관리

그룹을 생성, 조회, 삭제하는 기능을 제공합니다. 그룹에는 얼굴을 등록할 수 있으며 조회, 삭제도 가능합니다. 특정 그룹에 등록된 얼굴은 유사한 얼굴을 찾는데 사용이 됩니다.

### 얼굴 검증

기존에 등록되어 있는 얼굴과 이미지에서 감지된 얼굴이 얼마나 유사한지 수치화한 유사도 값을 반환해 줍니다.

### 얼굴 검색

특정 그룹에서 유사한 얼굴을 찾아주는 기능입니다. 이미지(감지한 얼굴들 중 가장 큰 얼굴을 사용) 또는 기존에 등록된 ID를 전달받아서 유사한 얼굴들을 찾아 가장 유사한 얼굴부터 정렬하여 반환해 줍니다.

## 얼굴 인식 기술 활용 예

* 모바일 앱 로그인 및 결제 확인
* 공항의 출입국 간소화 시스템
* 출입 및 출석 관리 또는 학사 관리 시스템
* 소프트웨어 전화 잠금 해제

## API 가이드

* https://docs.toast.com/ko/AI%20Service/Face%20Recognition/ko/api-guide/
* 기본적인 API 사용 순서
  1. **그룹 생성**
  2. 그룹에 **얼굴 등록**
  3. 이미지(URL) 및 ID(그룹에 얼굴 등록하면 반환됨)로 그룹에서 **얼굴 검색**
