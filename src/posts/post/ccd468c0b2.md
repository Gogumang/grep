## kakao tech meet

kakao tech meet은 카카오의 공개 기술 세미나로, 최신 기술 트렌드와 경험 및 노하우를 자주, 지속적으로 공유하며 개발자 여러분과 함께 성장을 도모하고 긴밀한 네트워크를 형성하고자 합니다.

두 번째 kakao tech meet에서는 카카오톡 Java App Server를 리팩토링한 내용과 배치 어플리케이션의 성능을 향상 시키는 다양한 방법들, 그리고 애자일로 개발 조직의 변화를 촉진한 이야기를 준비했습니다. 이어서, 발표에서 못다 한 이야기를 이끌어내고 참여자들과 소통할 수 있도록 패널토의를 진행합니다.

판교역에 연결된 카카오 아지트에서 열리는 이번 기술 세미나에 많은 관심과 참여 부탁드립니다. 앞으로도 카카오는 개발자 커뮤니티의 일원으로서, 개발자 커뮤니티와 함께 성장하기 위해서 꾸준히 노력하겠습니다.

### 발표 내용 \& 발표자 소개

![](https://images.gogumang.com/ccd468c0b2/02.png)

**(1) 카카오톡 Java App Server Refactoring 후기**

카카오톡 Java App Server를 리팩터링한 내용을 일반화하여 공유합니다. 세월의 흔적으로 많아진 가변 Context 클래스, 복잡하게 물고 물리는 의존성, 높아진 코드 복잡도를 어떻게 정리했는지, 예제로 일반화하여 하나씩 이야기하려고 합니다.리팩터링에 관심이 있으신 분, 레거시 코드를 유지 보수해야 하는 분이 듣길 추천합니다.

**발표자: @soo.lee(이상우)**

카카오 톡메시징파트에서 메시징 서버를 개발하고 있습니다. 유지 보수성, 테스트 용이성이 높은 구조를 좋아합니다.

*#refactoring #java #backend #의존성 #코드복잡도*

**(2) Spring Batch 애플리케이션 성능 향상을 위한 주요 팁**

배치 애플리케이션이 어느 구간에서 쉽게 느려지는지 파악하고, 이를 해결하기 위한 방법에 대해 다룹니다. 특히, IO 작업이 처리 시간에 큰 영향을 주는데, 이를 해결하기 위해 병렬 처리 및 벌크 IO 처리를 활용하여 IO 작업의 효율성을 높이는 성능 최적화 방법에 대해 다루게 됩니다.

배치 애플리케이션 개발자, 대량 처리에 관심있는 분이 듣길 추천합니다.

**발표자: @yun.cheese(김남윤)**

카카오페이 정산팀 Yun 입니다. Yun Blog를 운영하고 있으며, 서버 개발자로서써 좋은 코드 설계와 아키텍처에 관심이 많습니다.

*#spring batch #대량 처리 성능 최적화*

**(3) 애자일로 개발하면 빨리 끝난다던데?**

고군분투하면 모두가 행복해질까? 화목해 보이는 옆 팀, 왠지 개발도 잘하는 것 같은 옆옆 팀.

좋아 보이는 팀들의 공통점들을 보면서 우리 조직의 변화를 촉진할 씨앗을 찾아보시죠.

나의 퍼포먼스와 함께 조직의 퍼포먼스에 관심이 생긴 누구나 듣길 추천합니다.

**발표자: @jazz.k(김지훈)**

결국 서비스를 만드는 것도 사람이니까. 더 좋은 환경에서 일할수록 더 좋은 서비스가 만들어진다고 믿습니다. 더 좋은 환경을 만들고 싶은 애자일코치 재즈입니다.
