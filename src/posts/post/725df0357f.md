## 서비스 소개

![01.jpg](https://images.gogumang.com/725df0357f/01.jpg) Document Recognizer 서비스는 NHN Cloud의 OCR(광학 문자 인식) 기술을 통해 사업자등록증, 신용 카드, 신분증의 문자 영역을 인식하고 영역별 문자를 추출하는 기능을 제공합니다. 인식된 문서를 DB화하거나 문서 처리 자동화를 구현하는 고객사에서 활용할 수 있습니다.

## 신분증 분석

* 신분증(주민등록증, 운전면허증)의 주요 데이터를 추출하여 분석 결과를 제공합니다.
* 제3자 인증 기관을 통해 신분증 분석 결과의 진위를 확인할 수 있습니다. ![02.png](https://images.gogumang.com/725df0357f/02.png)

## 신분증 분석 기능 활용 예

* 문서를 자동으로 고객사 시스템에 등록하는 경우
* 문서 처리 자동화를 구현하는 경우
* 회계/재무 관리 자동화 솔루션을 구축하는 경우

## 콘솔 사용 가이드

* 콘솔에 신분증 이미지 파일을 업로드하여 분석 결과와 진위를 확인할 수 있습니다. 자세한 내용은 [사용자 가이드](https://docs.toast.com/ko/AI%20Service/Document%20Recognizer/ko/console-guide/#_7)를 참고하시기 바랍니다.

## API 가이드

* API를 통해 신분증 이미지 파일을 전달하여 분석 결과를 얻을 수 있고 신분증 분석 결과를 전달하여 진위를 확인할 수 있습니다. 자세한 내용은 [사용자 가이드](https://docs.toast.com/ko/AI%20Service/Document%20Recognizer/ko/api-guide-v2.0/)를 참고하시기 바랍니다.
