## Document Recognizer 서비스 소개

Document Recognizer는 NHN Cloud의 OCR(광학 문자 인식) 기술을 활용한 첫 번째 상품입니다. 머신러닝을 통해 사업자등록증 분석을 학습하였으며, 이미지의 문자 영역을 인식하고 영역별 문자를 추출하는 기능을 제공합니다. 현재는 사업자등록증만 가능하지만 추후 신분증, 신용카드 등 분석 가능한 문서들이 추가될 예정입니다.

## 주요 기능 및 특징

NHN Cloud 웹 콘솔을 통해 이미지를 업로드하고 분석 결과를 볼 수 있는 페이지가 존재합니다. 분석 API는 실제 서비스에서 사용할 수 있도록 REST API 형식으로 제공됩니다.

### **사업자등록증 분석**

* 사업자등록증의 문자 영역(bounding box)을 인식하고, 해당 영역의 문자 정보를 제공합니다.
* 인식한 문자 정보는 키(Key)-값(Value) 한 쌍으로 분석되며, 결과에 대한 신뢰 값(Confidence)을 제공합니다.

## Document Recognizer 서비스 활용 예

* 사업자등록증을 자동으로 고객사 시스템에 등록하는 경우
* 문서 처리 자동화를 구현하는 경우
* 회계/재무 관리 자동화 솔루션을 구축하는 경우
