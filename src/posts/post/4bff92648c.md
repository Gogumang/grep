금융사는 전자금융 거래법이나 전자금융 감독규정에 따라 운영 시스템에서 발생하는 로그가 위·변조되지 않도록 로그 데이터에 대한 무결성을 검증하고 감시하는 기능이 필요합니다. TOAST Log\&Crash Search에서는 이런 금융사의 요구 사항을 만족시키기 위해 장기 보관되는 데이터에 대한 무결성 검증 및 위·변조 내역에 대한 통보 기능을 제공하고 있습니다.

무결성(integrity)이란 간단히 말해서 데이터가 일부라도 훼손되거나 조작되지 않은 상태나 속성을 의미합니다. 외부 공격자나 권한이 없는 사용자가 접근하여 데이터를 위조하거나 변조하게 되면 데이터의 무결성이 깨졌다고 표현합니다.

TOAST Log\&Crash Search는 무결성을 보장하기 위해 내부에만 데이터를 보관하지 않고 외부 저장소인 TOAST Object Storage에 데이터를 저장하고 주기적으로 무결성을 검사하는 기능을 보유하고 있습니다.

# 외부 보관 설정

무결성 검증 기능을 사용하기 위해서는 우선 외부 저장소에 대한 접근 정보를 설정해둬야 합니다.

"설정" \> "로그 외부 보관 설정" 탭으로 이동하여 "추가" 버튼을 클릭하면 로그를 외부 저장소에 보관할 수 있습니다.

다음과 같이 외부 저장소의 엔드 포인트(URL), 리전, 버킷 이름을 설정함으로써 대상 저장소의 주소를 지정할 수 있습니다. 저장소에 접근하기 위해 필요한 기밀정보인 액세스 키와 비밀 키를 저장해두면 일정 시간마다 자동으로 외부 저장소에 접근하여 데이터를 저장합니다.

![1.png](https://images.gogumang.com/4bff92648c/01.png)

추가적으로, 저장이 반복적으로 실패하거나 위·변조가 발생하는 등 다양한 경우에 통지를 받을 수 있는 이메일 주소를 입력해둡니다.

# 무결성 검증 기능 설정

외부 보관 설정이 된 상태에서, "외부 로그 변조 알림" 토글 버튼을 활성화하여 "ON"으로 켜면 위·변조 발생 시에 알림을 받을 수 있습니다. 다음과 같이 TOAST Object Storage과 연동하기 위해 필요한 테넌트와 이메일 주소, 비밀번호를 입력하고 검증 버튼을 클릭하면 연동이 완료됩니다.

![2.png](https://images.gogumang.com/4bff92648c/02.png)

"사용 여부" 토글 버튼이 ON으로 켜져 있는지 확인하고 마지막으로 하단의 "저장" 버튼을 클릭하여 설정을 저장합니다.

무결성 검증 기능이 활성화되어 자동으로 동작하게 되며, 이후 외부 저장소에서 데이터의 무결성이 깨지는 경우가 발생하면 결과 수신 이메일 주소로 알림 메시지를 발송하여 사용자가 인지할 수 있도록 합니다.

향후 Amazon S3 등의 S3 인터페이스와 호환되는 외부 저장소까지 확대하여 지원할 계획입니다.
