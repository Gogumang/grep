### 소개

로그 외부 보관 설정 기능은 Log\&Crash Search로 수집한 로그를 외부 오브젝트 스토리지에 저장할 수 있는 기능입니다. Log\&Crash Search로 수집된 로그를 받아서 활용하고 싶거나, 로그의 장기 보관이 필요한 경우 이 기능을 사용하시면 됩니다. 외부 보관 기능은 S3 인터페이스를 사용하고 있어서, 토스트클라우드 OBS를 비롯한 S3 호환 인터페이스를 지원하는 오브젝트 스토리지는 모두 사용하실 수 있습니다. (토스트클라우드 OBS를 이용하는 방법은 OBS의 S3 API 가이드를 참고하시기 바랍니다.)

### 설정 방법

\[설정\] 메뉴의 \[로그 외부 보관 설정\] 탭 화면에서 '추가' 버튼을 누른 후, 로그가 저장될 S3 인증 정보와 버킷 정보 등을 입력하면 로그 외부 보관 기능이 활성화됩니다. ![1.png](https://images.gogumang.com/4d87447e07/01.png)

Log\&Crash Search에서는 수집된 로그를 시간 단위로 버퍼를 두고 아카이빙한 후, 주기적으로 S3 API를 통해서 사용자가 설정한 스토리지에 업로드 하는 방식으로 동작합니다. 로그는 스토리지에 다음과 같은 규칙으로 분할되어 저장됩니다.

* 파일 위치 : 버킷명/년/월/일/시/
* 파일명 prefix : 앱키-년월일시-archive
* 분할 파일 크기 : 최대 1GB

![2.png](https://images.gogumang.com/4d87447e07/02.png)

### 주의 사항

내부 버퍼 및 연동 스토리지의 상태에 따라서 파일의 업로드 간격은 일정하지 않을 수 있으며, 로그가 발생해서 외부 보관 저장소에 적재될 때까지는 최소 2시간 이상의 시간 간격이 있을 수 있습니다. 연동된 외부 스토리지의 인증 정보 변경 및 네트워크 통신 이슈 등으로 3회 이상 업로드에 실패했을 경우, 외부 보관 설정 기능이 자동 비활성화되고 '결과 수신'에 설정된 이메일로 문제가 있음을 통보합니다.
