9월 10일 오후, 카카오 판교아지트에서 프레임워크 관련 기술과 커뮤니티 활동을 주도하는 세계적인 프로그래밍 전문가 조시 롱([Josh Long](https://joshlong.com))을 모시고 ‘Spring Boot Meet Up’이 개최되었습니다. 조시 롱은 Spring Developer Advocate로서, Spring 프레임워크와 관련된 기술 및 커뮤니티 활동을 주도하며, VMware Tanzu에서 활동하고 있습니다. 다양한 콘퍼런스에서 강연하고, 기술 블로그와 책을 통해 Spring 생태계의 최신 동향과 모범 사례를 공유하고 있습니다.

Spring Boot Meet Up은 모든 카카오 그룹사 크루들과 함께, 온라인, 오프라인에서 동시에 진행되었습니다. 먼저 ‘조시 롱’의 메인 발표 세션으로 시작되어, Q\&A 세션으로 마무리되었는데요, 장장 두 시간이 넘는 시간이 순식간에 지나갔습니다. 온오프라인을 오가며 크루들과 다양한 질의응답을 세심하게 진행했습니다.

## 열정이 넘치는 라이브 세션

조시 롱(Josh Long)은 그의 ‘트레이드마크’인 빠른 말투와 유머 감각을 중심으로 참석한 모든 크루들을 이목을 끌어당겼습니다. 특히 라이브 코딩을 통해 Spring Boot 3의 새로운 기능들을 시연하며, 코드가 완성되고 결과물을 공유하는 모습에 크루들은 집중하면서 세션을 즐겼어요.

![밋업 시작과 동시에 라이브 세션을 진행하는 조시 롱과 깃헙의 내용에 집중하는 카카오 크루들](https://images.gogumang.com/2d47612df0/02.jpg)

![밋업이 진행되고 있는 현장 모습. 120분간 이 모습 그대로 집중하였습니다](https://images.gogumang.com/2d47612df0/03.jpg)

![조시 롱의 라이브 세션과 함께 실시간 코딩된 결과를 설명하는 모습입니다. 쉬지 않고 열정을 다하는 모습에 마음속의 박수를 계속 보내게 되었습니다](https://images.gogumang.com/2d47612df0/04.jpg)

라이브세션을 통해서 이뤄진 ‘Spring Boot Meet Up’의 주요 내용은 아래와 같습니다.

**1. Java 21의 가상 스레드 소개**

* 더 나은 확장성과 성능을 제공
* 기존 코드를 크게 변경하지 않고도 사용 가능

**2. Spring Modulith 프로젝트 소개**

* 모듈식 아키텍처 구축 지원
* 이벤트 기반 통신 및 모듈 간 의존성 관리 개선

**3. AI와 Spring의 통합**

* Spring AI 프로젝트를 통한 AI 기능 통합
* OpenAI 등 다양한 AI 모델과의 연동 가능

**4. 데이터베이스 및 벡터 저장소**

* PostgreSQL과 PGVector를 활용한 벡터 검색 기능
* 효율적인 데이터 처리 및 검색 방법 소개

**5. GraalVM과 네이티브 이미지 컴파일**

* 빠른 시작 시간과 적은 메모리 사용량
* 컴파일 시간이 길다는 단점 존재

**6. 리액티브 프로그래밍과 가상 스레드 비교**

* 두 접근 방식의 장단점 분석
* 상황에 따른 적절한 선택 방법 제시

**7. Spring Cloud 기능**

* 설정 관리 및 동적 업데이트를 위한 Spring Cloud Config
* 마이크로서비스 간 통신을 위한 Spring Cloud Bus

**8. 개발자 생산성 향상 팁**

* 효율적인 디버깅 방법
* AI 도구를 활용한 코드 리뷰 및 문제 해결

특히, 위의 8가지를 소개 및 강조하면서 세션 중에 소개된 코드와 자료는 GitHub에서 확인할 수 있도록 제공해 주었습니다(<https://github.com/joshlong/bootiful-spring-boot-2024>)

## 끊이지 않는 질문 vs 성심성의껏 답변, 뜨거운 Q\&A 세션

120여 분간의 라이브 세션, 발표가 종료된 이후에도, 현장과 온라인을 통해서 다양한 질문이 쏟아졌습니다. 조쉬는 각 질문에 상세하고 유머러스한 답변을 주관적인 의견과 레퍼런스를 소개하면서 위트 있게 제공했습니다.

![질의응답 세션에서는 카카오 크루들의 쏟아지는 질문에 차근차근 모두 답변해 주는 조시 롱의 모습에서 그가 지식 공유, 커뮤니티에 진심이라는 것을 현장에서 확인할 수 있었습니다](https://images.gogumang.com/2d47612df0/06.jpg)

![오프라인 현장 질문과 온라인 질문에 즉각 답변해 주는 조시 롱](https://images.gogumang.com/2d47612df0/07.jpg)

온오프라인에서 나눈 질문 중에서 기억에 남는 질문은 아래와 같은데요.

1. 조쉬가 사용하는 브라우저는?
2. 스프링 재시작 시 이벤트 재처리와 모듈 구동 문제
3. Webflux vs Virtual Thread의 장단점 비교

질문은 영어와 한국어로도 모두 가능했으며, **VMware Tanzu 한국 팀**에서 통역을 지원해 주셨습니다. 통역사가 조쉬의 답변을 번역하고 한글 질문을 영어로 전달하는 등 원활한 소통이 이루어지면서 조쉬 또한 개인의 지식 범위 및 라이브 세션과 동일하게 다양한 레퍼런스 내용들을 토대로 답변하는 활발하고 열정적인 질의응답 시간을 가졌습니다.

특히, 조시 롱은 각 질문에 상세하고 유머러스한 답변을 제공해, 마지막까지 자리에 참석한 크루들에게 큰 웃음을 함께 선사했습니다. 이후에는 함께한 크루들 함께 사진도 찍고 대화를 나누는 시간을 가져, 평소 개발자 커뮤니티와의 교류를 중요시하는 조쉬의 모습을 함께 엿볼 수 있었습니다.
> “카카오의 개발자 여러분, 여러분의 열정과 실력에 감동받았습니다. 함께 Spring의 미래를 만들어 갑시다!” (조시 롱의 마지막 인사)
