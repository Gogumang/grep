DataQuery는 SQL 쿼리 엔진을 제공하며, Object Storage와 같은 NHN Cloud 서비스와의 연동을 지원하는 서비스입니다.

## 주요 기능

* 개별 리소스가 할당된 쿼리 엔진 클러스터를 제공합니다.
* 표준 SQL 쿼리를 통해 데이터를 조회할 수 있습니다.
* 웹 콘솔 내에서 쿼리를 실행할 수 있습니다.
* 실행했던 쿼리 히스토리 및 정보를 확인할 수 있습니다.
* 실행 중인 쿼리를 모니터링할 수 있습니다.
* 외부 툴과 연동할 수 있는 엔드포인트를 제공합니다(사용자 개별 인증 적용).
* 연동 가능/예정 서비스
  * NHN Cloud Object Storage
  * NHN Cloud RDS for MySQL (MySQL)
  * (예정) NHN Cloud EasyCache (Redis)
  * (예정) MongoDB

![img_dataquery.png](https://images.gogumang.com/257a4f2eba/02.png)

## 서비스 대상

* Object Storage 내 데이터를 SQL 쿼리를 통해 분석하고 싶은 경우
* 스토리지, 관계형 데이터베이스 등 다양한 데이터 소스를 함께 쿼리 실행하여 분석하고 싶은 경우
