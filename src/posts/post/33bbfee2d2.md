### 소개

TOAST SMS와 Email 서비스에서는 광고 메시지 수신거부 등록에 대한 webhook 기능을 제공하고 있습니다.

일반적으로 webhook이란 "사용자가 정의한 HTTP callback"입니다. 풀어서 설명하자면, 특정 이벤트가 발생하면 사전에 등록해 둔 callback URL을 자동으로 호출하는 서비스 간 연동 방식을 의미합니다.

TOAST Notification에서는 광고 메시지 수신거부 등록 이벤트가 중요하다고 판단하여 우선 이 이벤트가 발생할 때마다 webhook을 전송하여 사용자에게 통지할 수 있는 기능을 마련하였습니다.

### Webhook 등록 방법

TOAST 콘솔에서 SMS 서비스의 "웹훅 관리" 메뉴로 접근합니다.

![1.png](https://images.gogumang.com/33bbfee2d2/01.png)

* "이벤트 타입" 필드를 선택합니다. SMS는 "광고 문자 수신 거부 번호 등록"을 선택할 수 있고, Email은 "광고 메일 수신 거부 주소 등록"을 선택할 수 있습니다. (향후 확대 제공 예정)
* "대상 URL" 필드에 사용자가 별도로 준비한 웹서비스의 POST URL을 입력합니다.
* "서명" 필드에 외부인이 추측하기 어려운 문자열을 입력합니다. Wbhook이 전송될 때, "서명"으로 등록한 문자열 값이 헤더로 전달됩니다. 미리 정해둔 서명 문자열과 일치하는지 판단하여 외부인의 무단 사용을 방지할 수 있습니다.
* "추가" 버튼을 클릭하여 등록합니다.

Webhook 메시지에 대한 자세한 API 가이드는 다음 사용자 가이드를 참고하실 수 있습니다. https://docs.toast.com/ko/Notification/SMS/ko/api-guide/

### 복수 이벤트 건 전송

내부적으로는 주기적으로 이벤트를 취합하여 webhook을 전송하기 때문에 하나의 webhook에 여러 이벤트가 포함되어 전송될 수도 있습니다.

### 향후 계획

현재는 webhook 기능이 광고문자 수신거부 주소등록 이벤트에 대해서만 제공되고 있기 때문에 제공범위가 제한적이지만, 향후에는 메시지 발송 단계 별로 정의된 이벤트를 좀 더 다양하게 확대하고 Push나 KakaoTalk Bizmessage에 대해서도 webhook 기능을 제공할 예정입니다.
