## AI Fashion 서비스 소개

AI Fashion은 다양한 카테고리 상품 데이터를 학습하여 패션 분야에 특화된 서비스를 제공합니다. 상품명이나 속성을 몰라도 이미지만으로 쉽고 빠르게 유사한 상품을 검색할 수 있어서, 다양한 가격대의 유사 상품을 제시하거나, 원하는 상품의 재고가 없을 때 유사 상품을 추천해 최적의 비즈니스 모델을 구현할 수 있습니다.

## 주요 기능

* 모든 기능은 UI 없이 REST API 형식으로 제공됩니다.

### **카메라 검색**

* 입력한 이미지에서 패션 상품을 실시간으로 감지하고 분석하여 등록된 상품들 중에서 유사한 상품을 검색하는 기능입니다.
* 이미지에서 감지된 상품들 중 사용자가 선택한 상품과 유사한 상품을 검색해 줍니다. ![camera_kor.png](https://images.gogumang.com/670f8ed71f/01.png)

### **유사 이미지 상품 추천**

* 등록된 상품 이미지와 유사한 상품을 검색하여 추천하는 기능입니다.
* 카테고리 정보를 활용하여 원하는 카테고리에 속한 상품만 필터링하여 추천할 수 있습니다. ![similar_kor.png](https://images.gogumang.com/670f8ed71f/02.png)

### **딥 태깅**

* 이미지로부터 카테고리, 색상, 소재, 패턴 등 다양한 속성 정보를 분석하여 태그 정보를 반환합니다.
* 쇼핑몰 등에서 사용 중인 상품 등록 관리 시스템에 연동하여 빠르고 정확한 상품 정보를 입력할 수 있고, 섬세한 검색 필터 구현에 활용할 수 있습니다.
* 현재는 의류에 대한 태그 정보만 지원하며, 추후 신발/가방/모자 등을 확장할 예정입니다. ![tagging_kor.png](https://images.gogumang.com/670f8ed71f/03.png)

## AI Fashion 서비스 활용 예

* 카메라 검색을 연동하여 상품 검색 기능을 제공하는 챗봇 서비스
* 이미지 기반의 검색 서비스를 제공하려는 온라인 쇼핑몰
* 상품 상세 페이지에서 유사한 상품을 추천하려는 경우
* 품절 상품의 대체재를 검색하여 추천하려는 경우
