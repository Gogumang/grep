![NHN클라우드 Word Suggestion 서비스 소개_230215.jpg](https://images.gogumang.com/3617820a05/01.jpg)

사용자가 입력한 단어를 교정하여 결과를 제공하는 서비스입니다. 쇼핑몰에서 가장 많이 사용된 단어들을 기반으로 개발되어 쇼핑 상품에 특화된 교정 서비스를 제공하고, 사용자가 직접 신조어나 동의어 등을 추가할 수 있어 더욱 사용자에게 특화된 서비스를 제공합니다.

## 주요 기능

* 단어 교정
  * 사용자가 입력한 단어를 교정하여 결과를 제공하는 기능입니다.
  * 기본 사전과 사용자 사전을 사용하여 교정합니다.
    * 기본 사전: 쇼핑몰 기준으로 한국인이 가장 많이 검색하는 약 70,000개의 단어로 구성되어 있습니다.
    * 사용자 사전: 사용자가 등록한 단어로 구성되어 있습니다.
  * 단어 교정 프로세스
    * 사용자 사전이 등록되어 있는 경우, 사용자 사전 → 기본 사전순으로 단어를 교정하여 제공합니다.

![01.png](https://images.gogumang.com/3617820a05/02.png)

* 사용자 사전 관리
  * 사용자가 추가로 교정을 원하는 단어를 관리하는 기능입니다.
  * 5,000개까지 등록/수정/삭제가 가능합니다.

## 서비스 이용 방법

### 서비스 이용 설정

* 서비스 이용 여부를 선택할 수 있습니다.
  * 서비스 이용 중지

    * 서비스 이용 설정의 **설정 안함** 을 선택하는 경우 Word Suggestion 서비스 이용과 과금이 중지됩니다. ![02.png](https://images.gogumang.com/3617820a05/03.png)
  * 서비스 이용 재개

    * 서비스 이용 설정의 **설정** 을 선택하는 경우 Word Suggestion 서비스 이용과 과금이 재개됩니다. ![03.png](https://images.gogumang.com/3617820a05/04.png)

### 단어 교정

1. 교정할 단어를 입력합니다.
2. 교정 요청을 통해 교정을 진행합니다.
3. 교정 결과값을 확인할 수 있습니다. ![04.png](https://images.gogumang.com/3617820a05/05.png)

### 사용자 사전 관리

1. 사용자 정의 단어를 등록합니다. ![05.png](https://images.gogumang.com/3617820a05/06.png)
2. 등록된 단어를 수정하거나 삭제할 수 있습니다. ![06.png](https://images.gogumang.com/3617820a05/07.png)
3. 등록된 전체 단어를 다운로드하거나 특정 단어를 검색할 수 있습니다. ![07.png](https://images.gogumang.com/3617820a05/08.png)

## 서비스 대상

* 단어 교정이 필요한 서비스를 구축하는 경우
* 이커머스 서비스에서 단어 제안이 필요한 경우
* 의류 쇼핑몰 등에서 상품 검색을 구축하는 경우
* 단어 제안을 통해 사용자의 편의성을 향상하고자 하는 경우
