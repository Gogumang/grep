## EasyCache 란?

2019년 12월에 출시된 EasyCache는 Redis(REmote DIctionary Server)를 클라우드 환경에서 제공하는 상품으로 간단한 설정으로 고가용성의 Redis 서버를 사용할 수 있게 해주는 서비스입니다.

EasyCache는 복제 그룹 단위로 Redis 서버를 관리하며, 이 복제 그룹을 생성, 관리하고 원활히 이용하기 위해 필요한 부가 기능을 제공하고 있습니다. 각각의 기능에 대해 간략히 살펴보겠습니다.

## 복제 그룹

복제 그룹은 1대, 또는 복수대의 Redis 서버로 구성되는 논리 단위로 복제 그룹을 구성하는 개별 Redis 서버는 노드라고 부릅니다.

![1.png](https://images.gogumang.com/ccaf3bd8f4/01.png)

처음 복제 그룹을 생성하면 마스터 1대로만 운영하는 Standalone이 되며, 이 경우 해당 노드에 장애가 발생하면 복제 그룹은 정상적으로 이용할 수 없는 상태가 됩니다. 복제 그룹을 이용할 수 없으면 어플리케이션에 영향이 있는 경우에는 복제 그룹에 노드를 추가하여 마스터 / 레플리카의 Replication 구성을 해 주어야 합니다.

![2.png](https://images.gogumang.com/ccaf3bd8f4/02.png)

### 접속

작성한 복제 그룹에 접속할 수 있는 URL은 생성 후에 상세 화면의 접속 정보 탭에서 확인하실 수 있습니다.

![3.png](https://images.gogumang.com/ccaf3bd8f4/03.png)

접속URL은 생성 화면의 VPC Subnet에서 지정한 VPC 서브넷과 같은 서브넷을 사용하는 Compute 상품의 인스턴스에서만 접속할 수 있습니다. VPC 서브넷에 관한 자세한 내용은 [여기](https://blog.naver.com/nhntoast/221616565304)를 참고해 주세요.

### 외부 네트워크에서의 접속

같은 VPC서브넷 이외의 네트워크에서 접속을 하고 싶다면, 플로팅 IP를 연결하면 됩니다. 플로팅 IP를 연결하면 아래와 같이 공인 도메인이 추가되며 이 공인 도메인을 이용하면 외부에서도 접속을 할 수 있습니다.

![4.png](https://images.gogumang.com/ccaf3bd8f4/04.png)

보안을 위해서 복제 그룹이 사용하는 VPC서브넷 이외의 접속은 차단하고 있습니다. 플로팅 IP를 연결하여 외부에서 접속할 경우에는 접속 제어 정보에 접속하려고 하는 대역의 CIDR을 추가해 주어야 합니다. ![5.png](https://images.gogumang.com/ccaf3bd8f4/05.png)

### 고가용성(High Availability)

고가용성은 장애가 발생하여도 지속적으로 정상 운영이 가능하게 하기 위한 기능입니다. EasyCache에서 고가용성을 사용하기 위해서는 마스터 / 레플리카의 Replication 구성만 해주면 됩니다.

레플리카를 추가하면 마스터를 감시하여 장애 감시시 자동으로 레플리카가 마스터로 승격됩니다. 어플리케이션 코드의 변경 없이 바뀌어진 마스터와 접속을 하게 하기 위해서는 EasyCache에서 제공하는 접속URL을 이용하여야 합니다. 접속URL은 도메인으로 되어 있으며, 해당 도메인은 마스터 노드에 접속하는 것을 보증합니다. 만일 마스터 노드에 장애가 발생하여 레플리카가 새로운 마스터 노드로 승격이 되어도 도메인으로 접속하게 되면 승격된 새로운 마스터로 접속을 하게 됩니다.

## 백업

복제 그룹은 스케줄을 등록하여 자동으로 백업을 작성할 수 있으며, 수동으로 특정 시점의 데이터 백업을 작성할 수도 있습니다. 백업은 메모리를 저장소로 이용하는 Redis의 특성상, 노드나 Redis 프로세스가 재시작 되면 데이터가 사라지게 되는 것을 방지합니다. 자동 백업은 복제 그룹 삭제시 같이 삭제되며, 수동 백업은 복제 그룹 삭제 여부와 관계 없이 남겨 둘 수 있습니다. 수동 백업과 자동 백업은 모두 보관 기간을 정하여 자동으로 삭제할 수도 있습니다.

작성한 백업을 이용하여 복제 그룹을 복원하면 백업 데이터를 갖은 새로운 복제 그룹을 작성할 수 있습니다.

![6.png](https://images.gogumang.com/ccaf3bd8f4/06.png)

## 프로파일 설정

프로파일은 변경이 가능한 Redis의 설정파일을 관리하기 위한 그룹입니다. 기본적으로 Default 프로파일이 제공되며 다른 설정을 사용하고 싶은 경우, 새로운 프로파일을 등록하여 등록한 프로파일을 이용하도록 복제 그룹을 생성, 또는 기존 복제 그룹을 수정하면 됩니다.

![7.png](https://images.gogumang.com/ccaf3bd8f4/07.png)

하나의 프로파일을 여러개의 복제 그룹에 공유할 수 있습니다. 이 경우, 프로파일을 수정하면 해당 프로파일을 사용하는 모든 복제 그룹에 변경 내용을 순차적으로 적용합니다. 특정 복제 그룹만 수정을 하고 싶은 경우에는 새로운 프로파일을 만들고 복제 그룹 수정 화면에서 새로 작성한 프로파일로 변경을 해 주세요.

## 알람

알람은 유저 또는 시스템에서 특정 이벤트가 발생하거나, 생성한 복제 그룹의 성능 정보를 모니터링하여 지정한 임계값 조건을 만족한 경우에 유저에게 메일, 또는 SMS를 보내는 기능입니다.

![8.png](https://images.gogumang.com/ccaf3bd8f4/08.png)

알람을 받고 싶으면 먼저 알람 규칙을 만들어야 합니다. 알람 규칙에서는 알람이 발생할 메트릭, 또는 이벤트 조건을 입력하고, 대상 복제 그룹과 수신 유저를 그룹으로 묶어 지정합니다. 이벤트 조건은 이벤트가 발생한 타이밍에, 메트릭 조건은 1분마다 수집되는 모니터링 데이터가 시스템에 유입되는 타이밍에, 작성한 알람 규칙에 일치하는지 판단하며, 일치할 경우에 지정한 유저에게 알람을 보냅니다.

## 이벤트

유저 또는 시스템에 의해 발생한 이벤트 정보를 확인할 수 있는 기능입니다. 이벤트와 연관된 리소스의 이름, 타입, 그리고 해당 이벤트가 발생한 시간과 이벤트에 대한 설명을 확인할 수 있으며, 정상적으로 종료되지 않은 이벤트의 경우에는 설명에 실패로 표시됩니다. ![9.png](https://images.gogumang.com/ccaf3bd8f4/09.png)
