## Log\&Crash Search의 Network Insight 기능 소개

Network Insight 기능은 앱과 서버 간의 네트웍 품질을 살펴볼 수 있는 기능입니다.

Log\&Crash Search의 \[Settings\] 메뉴의 \[로그 전송 설정\] 탭 화면에서 Network Insight 로그 전송 여부를 켠 다음, \[Network Insight\] 메뉴에서 \[URL 설정\] 탭 화면에서 서버 URL을 등록함으로써 쉽게 설정해서 사용하실 수 있습니다. SDK의 재배포없이도 앱에서 네트웍 품질 지표를 수집하는 기능이 활성화됩니다.

또한, 자체적으로 개발한 서버의 URL만을 등록할 수도 있지만, 여러 서드파티 SDK를 사용하는 경우에는 각각의 SDK가 접근하는 서버의 URL을 함께 등록하여 전체적인 네트웍 품질을 추적할 필요가 있습니다.

지연 시간과 오류율의 시간추이는 다음과 같은 챠트로 확인 가능합니다. 지연 시간은 앱이 HTTP 클라이언트로서 HTTP 서버에 접속하여 응답을 받기까지의 시간을 의미합니다. 오류율은 해당 시간 동안의 HTTP 요청의 평균적인 실패 비율을 의미합니다. ![1.png](https://images.gogumang.com/06077d3406/01.png)

권장하는 품질 기준은 다음과 같습니다.

* 지연 시간은 1.0초 미만이어야 함
* 오류율은 1% 미만이어야 함

전세계적으로 서비스하고 있는 앱의 경우에는 지역적 네트웍 품질 편차를 한눈에 살펴볼 수도 있습니다. ![2.png](https://images.gogumang.com/06077d3406/02.png)
