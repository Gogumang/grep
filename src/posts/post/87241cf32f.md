## Spring Framework의 특징

교육 내용은 놀랍게도 처음부터 Spring Framework를 바로 다루는 대신에,친절하게도 우선 Framework가 무엇인지, Library와는 어떻게 다른지 같은 내용부터 차근차근 진행되었습니다. 그리고 Spring Framework의 특징, 각각의 모듈들에 대한 구성, Spring 서브 프로젝트들에 대한 설명으로 내용이 이어졌습니다. 이어서 Spring Framework의 핵심은 POJO(Plain Old Java Object)이며, 이를 위한 세 가지 기술 - IoC/DI, PSA, AOP - 에 대해 자세히 설명하기 시작하였습니다.

이후 교육에서 다루었던 주요 내용은 대략 아래와 같았습니다.

## PSA (Portable Service Abstraction)

* 서비스 추상화란
* Spring 트랜잭션 서비스 추상화

서비스 추상화의 예로서 트랜잭션 서비스 추상화를 보여주었으며, 트랜잭션 서비스 추상화를 트랜잭션 적용 이전 상태부터 데모를 통해 상세히 설명해주었고, 스프링에서 어떻게 트랜잭션 서비스 추상화를 구현하고 있는지, 이러한 트랜잭션 서비스 추상화가 데이터 액세스 기술의 변경에도 어떻게 유지될 수 있는지 단계별로 데모를 통해 깊이 있게 잘 설명해주었습니다.
