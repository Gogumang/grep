`EasyCache` 서비스는 사용자가 직접 `Redis`를 설치하지 않고도 클라우드 환경에서 쉽게 이용할 수 있도록 해주는 `NHN Cloud`의 KVS 서비스입니다. 이번에 `EasyCache` 서비스에 새롭게 추가된 멀티 레플리카 기능에 대해 알아보도록 하겠습니다.

## 복제 그룹과 레플리카 노드

`EasyCache`에서 처음 복제 그룹을 생성하면 읽기/쓰기가 모두 가능한 마스터 노드가 만들어지게 되고 생성된 복제 그룹에 레플리카 노드를 추가하게 되면 추가된 레플리카 노드는 실시간으로 마스터 노드의 데이터를 복제하면서 평상시에는 마스터 노드와 함께 사용자 클라이언트의 읽기 요청을 분산 처리하여 읽기 성능을 향상시킬 수 있는 읽기 전용 노드로 동작하고 마스터 노드에서 장애가 발생할 경우 장애 조치에 의해 새로운 마스터 노드로 승격 가능한 예비 노드의 역할도 겸하게 됩니다.

새롭게 추가된 멀티 레플리카 기능으로 사용자는 하나의 복제 그룹에 최대 2대까지 레플리카 노드를 추가할 수 있게 되어 보다 향상된 읽기 성능과 고가용성 환경을 이용할 수 있습니다.

## 읽기 성능과 멀티 레플리카

마스터 노드와 레플리카 노드 1대로 이루어진 복제 그룹에서 읽기 전용 도메인을 설정하여 읽기/쓰기가 모두 가능한 마스터 노드 이외에 레플리카 노드에서도 읽기를 분산 처리하도록 구성하는 경우 레플리카 노드에 장애가 발생할 경우 읽기 전용 도메인의 바인딩이 마스터 노드로 변경되어 레플리카 노드가 복구될 때까지 마스터 노드로 읽기 부하가 집중되게 됩니다. ![1.png](https://images.gogumang.com/f601c5e4d4/01.png) ![2.png](https://images.gogumang.com/f601c5e4d4/02.png)

레플리카 노드가 2대인 멀티 레플리카로 구성된 복제 그룹의 경우, 마스터 노드를 포함해 총 3대의 노드에서 읽기를 분산 처리할 수 있고 1대의 레플리카 노드에 장애가 발생하더라도 마스터 노드에 읽기가 집중되는 현상을 피할 수 있습니다. ![3.png](https://images.gogumang.com/f601c5e4d4/03.png) ![4.png](https://images.gogumang.com/f601c5e4d4/04.png)

## 고가용성과 멀티 레플리카

마스터 노드와 레플리카 노드 2대의 멀티 레플리카로 구성된 복제 그룹의 경우 마스터 노드와 레플리카 노드 1대에서 동시에 장애가 발생할 경우에도 장애 조치가 가능하므로 다운타임을 최소화할 수 있습니다. ![5.png](https://images.gogumang.com/f601c5e4d4/05.png) ![6.png](https://images.gogumang.com/f601c5e4d4/06.png)

## 멀티 레플리카의 설정

1. 웹 콘솔에서 복제 그룹을 생성한 후 레플리카 노드를 1대 추가합니다. 2. 레플리카 노드 추가가 완료된 복제 그룹을 선택한 후 `노드 추가`를 클릭하여 2번째 레플리카 노드를 추가합니다. ![7.png](https://images.gogumang.com/f601c5e4d4/07.png) ![8.png](https://images.gogumang.com/f601c5e4d4/08.png) ![9.png](https://images.gogumang.com/f601c5e4d4/09.png)
