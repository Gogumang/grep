WEB Firewall은 웹 공격을 전문적으로 탐지/방어하는 보안 설루션으로, 고객의 웹서비스로 공격이 인입될 경우, 전용 설루션을 통해 탐지/방어함으로써 즉각적인 대응이 가능하도록 지원하는 서비스입니다.

TOAST WEB Firewall 은 고객 클라우드 환경의 웹 서버 앞단에서 프락시 방식으로 동작하여 모든 웹 트래픽을 검사하며, 외부에서 들어오는 웹 애플리케이션 위협 트래픽과 외부 정보 유출을 차단하여 웹 서버를 보호할 수 있습니다.

## 주요 기능 및 특징

* 웹 트래픽 보호 기능 : 웹 트래픽 내의 악의적인 요청 차단, 응답 트래픽의 변조 방지 및 민감정보 유출 차단
* 로드 밸런싱 기능 : L7 기반 부하분산 모드를 제공하여 1대의 웹 방화벽으로 다수의 웹 서버 보호 가능
* 고성능 트래픽 처리 : DDoS 공격 등 대량 트래픽 발생 상황에서도 안정적인 처리량(Throughput) 제공
* 위장 기능 : URL 응답 정보를 위장하여 웹 서버 URL 주요 정보 노출 방지
* 간편 정책 설정 기능 : 웹 트래픽을 학습하여 손쉬운 보안 정책 가능
* REST-API 지원 : REST-API를 통한 웹방화벽 설정 및 모니터링 가능
* 보안성, 안정성 보장 : WEB Firewall 솔루션은 GS / PCI-DSS / CC 인증 획득 및 OWASP Top 10, 국정원 8대 취약점을 완벽 대응

## 서비스 제공 방식

Self 서비스와 Managed 서비스를 제공하고 있으며, 웹 방화벽 인스턴스는 Self, Managed 서비스 모두 고객 클라우드 영역에 구축됩니다.

* Self 서비스
  * 고객이 직접 웹 방화벽을 구축하고 운영할 수 있도록 웹 방화벽 이미지 및 운영 가이드를 제공합니다.
* Managed 서비스
  * 전문 엔지니어를 통한 웹 방화벽 운영 대행 및 보안 관제 서비스를 제공합니다.
  * 과학기술정보통신부 지정 보안관제 전문기업의 24시간 보안 관제 서비스를 통해 보안 사고 발생 시 빠르게 대응할 수 있습니다.
  * 웹 방화벽 실시간 장애 모니터링 및 대응 서비스를 제공합니다.
  * Console의 현황 페이지에서 웹 방화벽 이벤트 및 보안 관제 업무 처리 현황을 실시간으로 확인할 수 있습니다.
  * 주기적인 패치 및 패턴 업데이트 관리 서비스를 제공합니다.
