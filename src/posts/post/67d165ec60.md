## **API플랫폼파트**

### 무슨 일을 하나요?

API플랫폼파트는 카카오 Open API 및 API 플랫폼 서비스를 만들고 운영합니다. API를 통해 카카오와 공동체의 방대한 데이터와 기능들을 여러 서비스와 연결하는 역할을 하고 있어요. 다양한 서비스에서 만나볼 수 있는 카카오 로그인은 [OAuth 2.0](https://www.rfc-editor.org/rfc/rfc6749) 기반 소셜 로그인 서비스로, API플랫폼파트의 대표적인 서비스 중 하나입니다.

API플랫폼파트에서는 대용량 트래픽을 처리하는 API 플랫폼을 개발하고, 안정적으로 운영하는 노하우를 배울 수 있어요. API플랫폼파트의 개발자들은 크고 작은 프로젝트를 주도적으로 추진합니다. 다양한 서비스 요구사항을 만족하기 위해 새로운 기능들을 직접 설계하고 구현합니다.

API플랫폼파트는 카카오와 공동체 서비스에서 API 플랫폼을 사용하거나 여러 기술을 오픈 API로 서비스할 수 있도록 컨설팅합니다. API 제공자, API 사용자 모두를 지원하기 위해서는 전문적 기술력뿐만 아니라 다양한 서비스에 대한 이해, 커뮤니케이션 능력, 폭넓은 사고력을 발휘하고 있어요.

API플랫폼파트의 서버 개발자 지원자격은 아래와 같아요.

* 3년 이상의 Java 기반 웹 서비스 개발/운영 경험
* Linux 플랫폼에서 웹 서비스 개발/운영 경험
