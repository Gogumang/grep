# 필요성

광고 메시지를 전송할 때, 광고 전송 사업자는 정보통신망법의 의무사항을 준수해야 합니다. KISA 가이드에 따르면 영리목적의 광고성 정보를 전송하는 경우에는 "광고"라는 문구와 발송자의 연락처, 그리고 수신 동의 철회 방법을 함께 노출해야 합니다. 이를 위반할 시에는 과태료가 부과될 수 있습니다.

TOAST Push에서는 광고성 메시지 발송 시에 정보통신망법을 준수할 수 있도록 "광고" 문구와 발신자 연락처, 수신 동의 철회 방법을 함께 포함해서 발송해주는 편의성을 제공합니다. 또한 광고성 메시지의 수신을 거부하는 사용자에게 광고성 메시지가 전송되지 않도록 자동으로 필터링하고, 광고성 메시지의 수신에 동의한 사용자라 하더라도 야간 시간 수신을 거부한 사용자에게는 오후 9시부터 오전 8시까지는 광고성 메시지가 전송되지 않도록 자동으로 필터링하는 기능을 제공하고 있습니다.

# 광고성 메시지 수신 동의 여부 처리방법

TOAST Push를 사용하시는 앱 개발사에서는 다음과 같은 방법으로 사용자의 수신 동의 여부를 받아서 TOAST Push 서비스에 저장해둘 수 있습니다.

우선 앱 개발사에서는 광고성 메시지에 대한 수신 동의 여부를 철회할 수 있는 방법을 제공해야 합니다. 일반적으로 앱에서는 알림 설정과 관련된 메뉴 화면을 제공하여 사용자가 직접 토글 버튼을 이용하여 수신 동의 여부를 켜거나 끌 수 있도록 제공합니다. (예. 앱의 메뉴 \> 설정 \> 알림 설정)

다음 3가지의 수신 동의 여부 컨트롤을 사용자에게 제공하면 됩니다.

* **모든 메시지에 대한 수신 동의 여부**
* **광고성 메시지에 대한 수신 동의 여부**
* **야간 광고성 메시지에 대한 수신 동의 여부**

이 3가지 수신 동의 여부의 값은 TOAST Push의 SDK나 API를 이용하여 TOAST Push에 저장할 수 있습니다. 이후 앱 개발사에서 광고성 메시지를 발송할 때 수신을 거부한 사용자는 자동으로 필터링되어 광고성 메시지를 수신하지 않게 됩니다.

## SDK를 사용하는 방법

* 사용자 UID를 저장하는 register() 메소드를 호출할 때 사용자의 수신 동의 여부를 Map 타입의 options 변수에 저장하여 호출합니다.
* 다음 코드 조각을 참고하여 KEY_AGREE_NOTIFICATION, KEY_AGREE_AD, KEY_AGREE_NIGHT_AD 값이 사용자의 의도를 잘 반영하도록 설정해야 합니다.

```java
// 이하 3개 옵션의 default 값은 false임
options.put(PushSdk.KEY_AGREE_NOTIFICATION, true); 
options.put(PushSdk.KEY_AGREE_AD, true); 
options.put(PushSdk.KEY_AGREE_NIGHT_AD, true); 
final int error = PushSdk.register(YOUR_APPKEY, YOUR_UID, new PushSdk.OnRegister() {
    @Override
    public void fire(int error) {
        // 매번 호출됨
        // error가 0이면 성공, 그 외의 값이면 실패를 의미함
    }
}, options);
```

## API를 사용하는 방법

* 토큰을 생성하는 API를 이용하여 사용자의 수신 동의 여부를 저장할 수 있습니다.
* isNotificationAgreement, isAdAgreement, isNightAdAgreement 키의 값이 사용자의 수신 동의 여부를 잘 반영할 수 있도록 설정되어야 합니다.

```
POST /push/v2.0/appkeys/{appkey}/tokens
Content-Type: application/json;charset=UTF-8
```

```json
{
"oldToken": "oldToken",
"token": "token",
"isNotificationAgreement": true,
"isAdAgreement": true,
"isNightAdAgreement": true,
"pushType": "GCM",
"timezoneId": "Asia/Seoul",
"uid": "uid",
"country": "KR",
"language": "ko"
}
```

자세한 내용은 TOAST Document에서 확인할 수 있습니다.

* http://docs.toast.com/ko/Notification/Push/ko/sdk-guide/
* http://docs.toast.com/ko/Notification/Push/ko/api-guide/

## 메시지 발송 방법

광고성 메시지를 발송하는 방법은 다음과 같습니다.

1. TOAST Cloud Push 웹콘솔 화면 \> Message 탭에 접근합니다.
2. Message 영역의 Message Type을 AD로 변경합니다. (중요)
3. Contact 입력란에 발신자 연락처를 기재합니다.
4. Remove Guide 입력란에 광고성 푸시 수신 동의 철회 방법을 기재합니다. 일반적으로 앱 내의 알림 설정 메뉴를 찾을 수 있는 방법에 대한 안내 문구를 기재하면 됩니다. ![push_message.png](https://images.gogumang.com/f52ba6f64d/01.png)
