### 소개

TOAST Push는 Rich Message 기능을 제공합니다. Rich Message 기능이란 단말기가 알림(notification) 메시지에 **버튼이나 이미지, 동영상, 음원 등의 멀티미디어를 함께 노출**하는 것을 의미합니다. 이를 통해 사용자에게 시각/청각적인 인상을 줌으로써 앱 실행이나 웹 페이지 방문을 유도할 수 있습니다.

Android 단말기와 iOS 단말기 화면의 미리 보기 기능을 이용하여 실제 메시지가 어떻게 구성되는지 직접 확인할 수 있습니다.

### 버튼 추가

![1.png](https://images.gogumang.com/06cc273842/01.png) "버튼"은 특정 URL을 열거나 앱을 실행하는 용도로 사용할 수 있습니다.

### 멀티 미디어 추가

![2.png](https://images.gogumang.com/06cc273842/02.png) "미디어"는 이미지, GIF, 동영상, 소리 등의 멀티미디어를 활용할 수 있으며 메시지 중앙의 가장 큰 영역에 노출됩니다. 미디어의 웹 URL을 지정하거나 앱 내부의 리소스 경로를 지정할 수 있습니다.

### 큰 아이콘 등록

![3.png](https://images.gogumang.com/06cc273842/03.png) Android에서 메시지 텍스트 오른쪽에 아이콘을 배치하려면 "큰 아이콘"에 아이콘 이미지 URL을 등록할 수도 있습니다.

### 그룹 기능

![4.png](https://images.gogumang.com/06cc273842/04.png) 비슷한 메시지가 다량 발송되었을 때, 같은 종류라고 묶어서 보여주는 기능도 활용할 수 있습니다. "그룹"의 키를 같은 값으로 지정하면 하나의 메시지 그룹으로 모아서 알림(notification)을 표시해주는 기능이 Android에서 아래 그림과 같이 제공되고 있습니다. 다만, 단말기 제조사마다 메시지 그룹을 묶어서 보여주거나 펼치는 동작은 조금씩 다를 수 있습니다.

![5.png](https://images.gogumang.com/06cc273842/05.png) (출처: Android Developers 공식 홈페이지)

### OS별 미리 보기 기능

콘솔 화면 우측에 OS 별로 미리 보기 화면이 렌더링 되어 직접 눈으로 확인할 수 있습니다. 모바일 OS마다 기능 요소에 대한 지원 여부가 다르니 미리 보기 화면에서 확인이 필요합니다. 예를 들어 "큰 아이콘"은 Android에서만 지원되고 iOS에서는 지원되지 않습니다.

![6main.png](https://images.gogumang.com/06cc273842/06.png)

Push의 Rich Message 기능은 SDK 버전 업데이트가 필요할 수 있습니다. TOAST SDK를 사용하는 경우, Android는 1.13.0 이상, iOS는 0.12.0 이상이 요구됩니다. Push SDK를 사용하는 경우에는 1.7.0 이상을 사용하시면 됩니다.
