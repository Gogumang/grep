ShortURL 서비스는 단축 URL을 생성해 주는 서비스입니다. 긴 URL을 짧게 줄여서 글자 수 제한이 있는 SMS 메시지에 실어 보내거나 사용자가 눈으로 읽고 쉽게 옮겨 적을 수 있도록 도와줍니다. 또한, 사용자에게 이미 공개된 URL이 있으나 실제 서비스 URL이 자주 바뀌기 때문에 API를 이용하여 동적으로 단축 URL을 생성하고 실제 서비스 URL과의 연결 관계를 등록할 수도 있습니다.

## 주요 기능

ShortURL 서비스에서 기본으로 제공하는 도메인인 nh.nu 으로 시작하는 단축 URL을 사용할 수 있습니다. 처음에는 서너 글자에서 시작하고 누적 사용량에 따라 점차 길어지게 됩니다. 다음에 새롭게 생성될 단축 URL을 예상하지 못하도록 임의의 문자 조합으로 URL 후반부(back-half)가 선택됩니다.

![URL 추가.png](https://images.gogumang.com/ae9e719e42/01.png) 서비스 URL을 "원본 URL" 입력란에 기입하고, "도메인"을 ShortURL에서 기본으로 제공하는 nh.nu 를 사용하거나 아니면 사전에 등록해둔 고객 소유의 도메인을 선택할 수도 있습니다. "URL 종류"는 임의의 문자 조합으로 만들어진 URL 후반부가 사용되도록 "자동"으로 선택할 수도 있고, "사용자 정의"를 선택하여 다음 단락에서 설명하는 것처럼 사용자가 익숙한 단어를 선택하여 사용할 수도 있습니다.

이렇게 만들어진 URL은 다음과 같이 "조회" 탭의 "URL" 서브 탭에서 조회하거나 편집, 삭제가 가능합니다. ![URL 관리.png](https://images.gogumang.com/ae9e719e42/02.png)

## 사용자 지정 URL 후반부(back-half) 기능

익숙한 영어 단어를 이용하여 단축 URL을 구성하고 싶은 경우, 약간의 추가 비용을 치르고 URL 후반부를 선점할 수도 있습니다. 예를 들면, https://nh.nu/cola 와 같은 URL을 가질 수 있게 됩니다.

## 고객의 자체 도메인 지원

nh.nu 도메인도 충분히 짧기 때문에 일반적인 사용에 있어서는 충분하겠지만, 고객이 자체적인 도메인과 SSL 인증서를 확보하고 있는 경우에는 nh.nu 도메인 대신에 자체 도메인 사용을 원할 수도 있습니다. 그래서 자체 도메인을 사용할 수 있도록 도메인과 SSL 인증서를 관리하는 기능을 제공하고 있습니다.

고객이 보유한 자체 도메인을 사용하는 경우에는, 앞서 소개한 사용자 지정 URL 후반부 기능은 당연히 추가 비용이나 제한 없이 사용할 수 있게 됩니다.

요즘 사용하는 대부분의 웹브라우저는 https를 필수로 요구하기 때문에 가급적 자체 도메인을 사용할 경우, SSL 인증서를 업로드하여 함께 사용하는 것이 바람직합니다.

"관리" 탭의 "도메인" 서브 탭과 "SSL 인증서" 서브 탭에서 각각 도메인과 SSL 인증서를 관리할 수 있습니다.

## 캠페인 기능

캠페인 기능을 사용하여 특정 이벤트에서 사용할 URL들을 모아두고 관리할 수 있습니다. 하나의 프로젝트 내에서 캠페인 이벤트 별로 다수의 단축 URL을 분리해서 관리할 때 편리합니다.

## 기타 편의 기능

### API

웹 콘솔뿐만 아니라 API를 이용하여 단축 URL을 관리할 수 있습니다. 자세한 내용은 다음 사용자 가이드를 참고하시기 바랍니다. https://docs.toast.com/ko/Application%20Service/ShortURL/ko/api-guide/

### QR 코드

웹 콘솔에서는 단축 URL을 QR 코드로 생성해 주기 때문에 사용자에게 QR 코드를 전달하여 더욱 쉽게 서비스에 접근할 수 있도록 해줍니다.
