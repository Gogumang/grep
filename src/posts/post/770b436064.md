Server Security Check는 신규 또는 운영 중인 시스템의 보안 취약점을 점검하고, 발견된 취약점에 대한 대응 방법을 제공하는 서비스입니다.

시스템의 주요 보안 설정 값을 점검하고 조치해 잠재적 취약점을 제거할 수 있습니다. 발견된 보안 취약점을 사전에 조치해 유지보수 비용을 절감할 수 있으며, 고객에게 안정적 서비스를 제공하여 기업 이미지를 향상시킬 수 있습니다.

### 주요 기능

* 인프라 특성을 고려한 점검 기준
  * 주요정보통신기반시설, 전자금융기반시설 보안 기준을 바탕으로 체크리스트를 만들어 점검을 수행합니다.
    * 주요정보통신기반시설 : 행정, 통신, 금융, 에너지 등 국가·사회적으로 중요한 서비스를 제공하는 시설
    * 전자금융기반시설 : 전자금융거래에 이용되는 정보처리시스템 및 「정보통신망 이용촉진 및 정보보호 등에 관한 법률」 제2조제1항제1호에 따른 정보통신망
* 취약점 대응 방법 제공
  * 발견된 보안 취약점에 대한 근본적인 대응 방안을 제공합니다.

### 서비스 대상

* 신규 시스템의 보안 취약점 점검이 필요한 경우
* 운영 중인 시스템의 보안 취약점 점검이 필요한 경우
* 보안 인증 획득을 위해 취약점 점검이 필요한 경우
* 해킹 사고로 인해 보안 대책 마련이 필요한 경우

### 특이 사항

* 서비스 문제로 점검이 중단된 경우에는 이용 요금이 과금되지 않습니다.
* Agent 점검 중단 시 지원 서비스를 제공합니다.

### Agent

* 웹 콘솔에서 선택한 설정으로 취약점 점검을 수행하고, 점검 결과를 서버로 전송합니다.

### 웹 콘솔

* Agent 실행 스크립트를 제공하고, 서비스 이용 현황과 점검 결과를 확인할 수 있습니다. ![3.png](https://images.gogumang.com/770b436064/03.png) \[그림3\] Agent 실행 스크립트 제공 및 이용 현황 확인

* 보안 점검이 완료되면 발견된 취약점에 대한 위험도 별 통계와 세부 결과를 웹 콘솔을 통해 확인할 수 있습니다. ![4.png](https://images.gogumang.com/770b436064/04.png) \[그림4\] 점검 결과 및 상세 점검 결과 확인

* 가이드 버튼을 클릭하면 해당 점검 항목에 대한 근본적인 대응 방안을 확인할 수 있습니다. ![5.png](https://images.gogumang.com/770b436064/05.png) \[그림5\] 대응 방안 가이드 확인

* 상세한 이용 방법은 [콘솔 사용 가이드](https://docs.toast.com/ko/Security/Server%20Security%20Check/ko/console-guide/)를 참고하시기 바랍니다.
