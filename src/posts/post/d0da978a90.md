![](https://images.gogumang.com/d0da978a90/01.png)

여기어때에서 숙소를 탐색하는 방법은 크게 두 가지가 있어요. 하나는 ‘**카테고리홈** ’을 통해 숙소 유형별로 지역을 둘러보는 것이고, 다른 하나는 ‘**검색 기능**’을 이용해 키워드를 직접 입력하는 방식이죠. 카테고리홈은 호텔, 모텔, 펜션처럼 어떤 숙소를 찾을지 정해놓은 사용자들에게 딱 맞아요. 반면, 검색 기능은 원하는 조건이 명확한 사용자들이 자주 활용하죠. 이번 글에서는 카테고리홈에 검색 기능을 추가하면서 느낀 점과 경험을 함께 나눠보려고 해요.

![](https://images.gogumang.com/d0da978a90/02.png)

### 카테고리홈의 불편함은 무엇이었을까?

카테고리홈은 특정 숙소 유형을 찾으려는 사용자에게 꽤 유용한 탐색 방법이에요. 예를 들어, 호텔 카테고리를 선택하면 호텔만 쏙쏙 골라볼 수 있으니까요. **하지만, 기존 카테고리홈에는 두 가지 아쉬운 점이 있었어요.**

① **사용자 기대와의 어긋남**

기존 지역 리스트에서 상위 지역을 찾기가 어렵고, 하위 지역 그룹도 직관적이지 않았어요. 예를 들어, ‘강남/역삼/삼성/논현/선릉’이 하나의 그룹으로 묶여 있는데, 어떤 기준으로 묶여 있는 건지 알기 어렵고, ‘서초/신사/방배’는 따로 떨어져 있어 애매했죠.

![](https://images.gogumang.com/d0da978a90/03.png)

② **구조적 개선의 한계점**

“그럼, 지역 그룹을 새로 묶으면 되지 않을까?”라는 생각이 들지만, 지역 그룹을 단순히 분리하거나, 재구성하는 것은 비즈니스 운영에 큰 영향을 줄 수 있어 지역 구조 변경은 어려웠어요. 그래서 사용자 경험을 개선하면서도 비즈니스적인 손실을 최소화할 방법이 필요했어요.

### 검색 기능을 넣는다면 해결될까?

기존 지역 리스트를 재구성하는 대신, 사용자가 원하는 숙소를 더 쉽게 찾을 수 있도록 ‘검색’ 기능을 카테고리홈에 추가했어요. 이 검색 기능의 목표는 크게 두 가지였어요.

① **구매 전환율 및 GMV(거래액) per User의 유지**

검색 기능 자체가 새로운 것은 아니기 때문에 큰 성과를 기대하기보다는, 구매 전환율과 GMV가 기존 수준을 유지하는 것이 목표였어요.

② **PDP(숙소 상세 페이지) 전환율 상승**

카테고리홈은 사용자가 탐색을 시작하는 첫 단계로, 사용자가 둘러보기 정도의 의도를 가지고 있을 거예요. 그렇기 때문에 숙소 리스트에서 더 많은 사용자가 셀러 카드를 클릭해서 PDP(숙소 상세 페이지)로 넘어간다면, 사용자가 원하는 제휴점을 손쉽게 발견할 수 있도록 리스트를 제공했다는 것을 의미하므로 보다 적극적인 사용자의 의도가 들어간 행동이라고 생각할 수 있어요.

물론, 사용자가 입력한 검색 키워드 또한 사용자의 의도가 들어간 행동이지만, 검색 기능 자체가 카테고리홈에서는 신규 기능이기 때문에 (A/B 테스트에서) 기존의 그룹과 비교할 수 없어서 모니터링 지표 정도로만 참고했어요.

### 카테고리홈에 검색을 더하다

카테고리홈 검색은 매우 명료한 정책을 가지고 있어요. 카테고리홈에 검색 기능을 추가하면서도 기존 검색 로직을 그대로 유지했어요. 다만, 선택한 카테고리에 맞는 숙소만 검색 결과에 나타나도록 조정했죠. 여기에 기존 비즈니스 구조가 유지될 수 있게 여러 고민이 필요했어요.

***지극히 개인적인 기대 효과***

검색 기능 덕분에 사용자는 이제 제한적인 지역 리스트에서 벗어나 훨씬 자유롭게 숙소를 탐색할 수 있게 되었어요. 마치 묶여있던 손발이 풀린 느낌이랄까요? PO로서의 개인적인 기대는, 사용자가 어떤 카테고리에서 어떤 탐색 패턴을 보이는지 데이터를 통해 파악하고, 이 데이터를 차후 더 나은 사용자 경험을 제공하는 데 활용하는 거였어요.

**A/B테스트 결과는?**

![](https://images.gogumang.com/d0da978a90/04.png)

검색 기능을 추가한 후, PDP(숙소 상세 페이지) 유입률이 눈에 띄게 상승했어요. 기존에는 PLP(숙소 리스트 페이지)를 통해서만 숙소를 확인할 수 있었지만, **이제는 CSRP(카테고리 검색 결과 페이지)가 추가되면서 경로가 두 개로 늘어난 거죠. 결과적으로 더 많은 사용자가 상세 페이지로 이동했고, 구매 전환율과 GMV per User도 유의미하게 증가했어요.**

GMV per User까지 상승한 것은 큰 의미가 있었어요. 사용자가 가격이 더 높더라도 원하는 숙소를 발견했기 때문에 구매를 한 것이죠. 이는 탐색 경험이 개선되었다는 점에서 목표를 달성한 것으로 볼 수 있어요. 또한, 이번 실험 결과는 사용자뿐만 아니라 비즈니스적 측면에서도 긍정적인 영향을 미쳤는데요.

특히, 기존에는 SRP(검색 결과 페이지)를 탐색하던 사용자 중 많은 수가 CSRP(카테고리 검색 결과 페이지)로 이동한 것을 확인할 수 있었는데요. 이는 검색을 선호하는 사용자들도 CSRP(카테고리홈 검색 기능)을 사용함으로써 더 많은 사용자가 유입된 거죠. 덕분에 카테고리홈의 비즈니스 요구사항도 효과적으로 반영할 수 있었어요.

### 기존에 없던 ‘카테고리홈 검색’,
사용자들은 어떻게 쓸까?

사용자들이 카테고리홈 검색을 어떻게 쓰는지 설명하기 앞서, 자동완성 키워드와 엔터(Enter) 검색에 대해 간단히 설명드릴게요.

![](https://images.gogumang.com/d0da978a90/05.png)

* **자동완성 키워드**는 사용자가 키워드를 입력할 때, 시스템이 추천하는 키워드를 아래에 보여주고, 사용자가 그 추천 키워드를 클릭하는 경우를 말해요.
* 반면, **엔터 검색**은 사용자가 키워드를 직접 입력한 후, 키패드의 엔터를 눌러 자신이 입력한 자유 키워드로 검색 결과를 확인하는 방식을 의미해요.

카테고리별로 사용자의 검색 패턴을 분석해봤는데, 흥미로운 점을 발견했어요. 모텔 카테고리에서는 사용자가 지하철역명을 자동완성으로 많이 선택했고, 엔터 검색에서는 소지역명(예: 강남, 홍대)을 많이 입력했어요. 반면, 호텔과 펜션 카테고리에서는 제휴점명을 자동완성으로 검색하고, 대지역명(예: 강릉, 여수)을 입력하는 패턴이 있었죠. 이를 통해 모텔 사용자는 보다 세부적인 지역을 찾고, 호텔과 펜션 사용자는 이미 특정 제휴점을 염두에 두고 있다는 결론을 내릴 수 있었어요.

### 검색 기능 실험이 성공한 이유

**카테고리홈에 검색 기능을 추가한 것은 사용자에게 ‘자유로운’ 탐색 옵션을 제공했기 때문에 성공할 수 있었던 것 같아요. 사용자들이 이미 익숙한 기능을 통해 제한적이었던 지역 탐색 경험을 개선하면서, 더 개방적인 탐색 환경을 만들어준 것도 성공의 큰 요인이었죠.**

이번 실험과 검색 기능을 통해 카테고리별로 사용자의 탐색 의도를 파악할 수 있는 데이터를 얻게 되었어요. 이 데이터를 앞으로 더 적극적으로 활용할 계획입니다. 예를 들어, 사용자가 원하는 제휴점을 더 쉽게 찾을 수 있도록 돕고, 다양한 혜택을 제공하는 제휴점을 빠르게 추천할 수 있을 것으로 기대하고 있어요.

### 마무리하며

10개월이라는 긴 시간이 지나서, 모텔, 호텔, 펜션, 게스트하우스, 캠핑까지 다양한 카테고리에 검색 기능을 추가하는 프로젝트가 마침내 완료되었습니다. 이렇게 많은 카테고리에 검색 기능을 반영하게 될 줄은 저도 미처 예상하지 못했어요.

사실 이 프로젝트는 제가 여기어때에 입사한 후 처음으로 맡은 메인 프로젝트였어요. 그래서 함께 일할 동료들과 친해지는 것부터, 기존의 레거시 정책을 파악하는 일까지 모든 과정이 쉽지는 않았어요. 그 과정에서 가장 중요했던 스킬은 **정책의 우선순위를 빠르게 정리하고 공유하는 것**이었어요. 프로젝트의 범위가 커지면 아무리 정책서를 꼼꼼하게 작성해도 몇 가지는 빠뜨리기 마련이거든요. 그럴 때는 중요한 기능과 덜 중요한 기능을 신속하게 정리하고, 모두가 같은 방향으로 일할 수 있도록 조율하는 것이 필요했어요.

특히 작업 기간이 길어질수록 함께 하는 동료들이 지칠 수 있다는 점이 가장 걱정됐어요. 모두가 좋은 결과를 위해 열심히 일하고 있었기 때문에, 그 과정이 활기차고 긍정적으로 유지되길 바랐죠.

끝으로 ‘사용자가 느끼는 불편한 지점에 익숙한 기능을 더하면 시너지가 크다’는 점을 경험했어요. 익숙한 기능이 주는 강력한 효과를 발견할 수 있었던 시간 아닐까 싶어요.
