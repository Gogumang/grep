Maps API는 오랫동안 내비게이션 기술을 축적해 온 **아이나비의 25년간의 자체 기술력**과 노하우가 집적된 지도, **LBS 솔루션을 기반**으로 쉽고 정확한 **지도, 통합 검색, 경로탐색** 등 다양한 기능을 HTTP REST API로 제공합니다. PC와 모바일 환경에서 지도 서비스 개발이 가능하도록 JavaScript 기반 Web 지도 API , Android 지도 SDK , iOS 지도 SDK를 제공하므로, 손쉽게 위치 기반 서비스 개발에 활용할 수 있습니다.

이외에도, 아이나비의 기술이 녹아든 모빌리티 서비스 특화 기능을 개방하고, 위치 기반의 빅 데이터 시각화 솔루션을 제공함으로써 급성장하고 있는 모빌리티 서비스 생태계 및 빅 데이터 업계를 전폭적으로 지원할 예정입니다.

* 지도의 기본에 충실한 **다양한 기능 지원** (다양한 영역의 서비스 개발에 사용 가능) 스마트 시티, 통신서비스, 엔터테인먼트, 부동산, ,여행, 모빌리티 서비스, 의료 서비스, 관제 등 다양한 영역에서의 위치 정보 활용
* 아이나비만의 **차별화된 기능** (위치기반 빅데이터 시각화, 교통 정보 반영, 다중 멀티 탐색 등) 모빌리티 서비스 특화 기능, 위치기반 빅데이터 시각화, 교통 정보 반영 등(지속 업데이트)
* 다양한 지도 및 기능, 데이터를 바탕으로 **사용자의 필요에 따른 커스터마이징 활용 가능**
* **User-friendly한 환경**으로 손쉽고 편리하게 사용 가능

## 지도 서비스

### 부드럽고 선명한 지도 서비스

Web GL과 벡터 타일을 함께 이용함으로써 고해상도의 매끄러운 줌, 회전, 기울기 설정이 가능합니다. ![2.gif](https://images.gogumang.com/e9bb252fd8/02.gif)

### 다양한 지도와 Data 레이어 제공

일반지도, 항공지도, 하이브리드 지도와 Static Map(정적 지도), 실시간 교통정보 레이어, 전국 자전거 지도 레이어 등을 제공합니다. ![3.png](https://images.gogumang.com/e9bb252fd8/03.png)

### 마커, 마커 클러스터링, 정보창, 폴리곤, 폴리라인, 서클 등 다양한 기능

지도에서 쉽게 사용할 수 있는 230개 이상의 API 기능을 제공합니다. ![4.png](https://images.gogumang.com/e9bb252fd8/04.png) ![5.png](https://images.gogumang.com/e9bb252fd8/05.png)

### 배경 지도와 데이터 레이어 간의 시각화 효과(위치 기반 빅 데이터 시각화)

빅 데이터 분석 데이터를 배경 지도 위에 다양한 라이브러리를 이용하여 시각화할 수 있습니다. ![6.png](https://images.gogumang.com/e9bb252fd8/06.png)

### 빅 데이터 분석을 통한 지도 주기 데이터 표출

차량 내비 목적지 정보를 활용한 빅 데이터 분석, 통계를 통해 지도 주기 데이터를 선별하여 표출합니다.

## 통합 검색

아이나비의 최신 검색 엔진 기술을 이용하여 정확하고 유용한 검색 결과를 제공합니다.

### 통합 검색 하나로 모든 검색 가능

상호명, 전화번호, 주소(지번주소 \& 도로명), 카테고리 검색(주유소, 편의점, 음식점, 병원 등), 초성 검색 등 한번에 검색 할 수 있습니다.

### 다양한 공간 검색 옵션 제공

명칭(정식, 축약, 확장명칭), 지번주소, 도로명 주소, 행정코드, 분류(업종), 전화번호, 현재 위치와의 거리(공간검색 시), 위치 좌표, 탐색 좌표 등 검색 결과를 제공합니다.

### 정확하고 유용한 검색 결과 제공

명칭(정식,축약, 확장명칭), 지번주소, 도로명 주소, 행정코드, 분류(업종), 전화번호, 현재 위치와의 거리(공간검색 시), 위치 좌표, 탐색 좌표 등 검색 결과를 제공합니다.

### POI 상세 검색, 하위 시설물 검색

홈페이지, e-mail, 팩스번호, 교통편, 유가정보 등 상세 정보와 건물의 입구, 주차장 등 하위 시설물에 대한 확장 검색 결과를 제공합니다.

### 추천어 검색

검색어를 조회 빈도가 많은 검색어로 추천해서 검색할 수 있도록 제공합니다.

### Geocoding(주소 → 좌표)

주소를 지리 좌표(WGS84 좌표)로 변환할 수 있는 API를 제공합니다.

### Reverse Geocoding(좌표 → 주소)

지리 좌표(WGS84 좌표)를 주소로 변환할 수 있는 API를 제공합니다.

## 경로 탐색

실시간 교통정보, 통계 교통정보를 반영한 스마트한 경로 탐색을 통해 빠르고 쉬운 길 찾기 서비스를 제공합니다.

### 다양한 경로 탐색 옵션 제공

다양한 경로 탐색 옵션(추천 경로, 무료도로만 탐색, 최단거리 탐색 등)으로 최적의 경로를 제공합니다.

### 결과 제공

경로 탐색 결과 경로를 그릴 수 있는 포인트 정보 외에 도로 구간별 교통정보 색상, 속도, 거리, 도로 종류 등의 정보를 제공합니다.

### 경로 다중 출발지 탐색, 경로 다중 목적지 탐색(모빌리티 서비스 특화 기능)

여러 차들 중에 어떤 차가 가장 빨리 나에게 올 수 있는지 멀티 탐색 요약이 가능한 다중 출발지, 다중 목적지 탐색 요약 API를 제공합니다. 일반적으로, 직선 거리 계산이 아닌 실제 경로를 멀티 탐색하여 거리와 시간을 비교, 가장 가깝고 짧은 지점을 알려드립니다. ![7.png](https://images.gogumang.com/e9bb252fd8/07.png)

### 선명하고 다양한 기능의 StaticMap(정적지도)

벡터 지도를 원하는 Size의 정적 지도로 생성, 2배 확대의 Retina 기능을 제공하여 고해상도의 선명한 Static Map 기능을 제공합니다. 회전, 기울어진 상태 그대로 지도 생성이 가능하며 원하는 위치에 원하는 마커와 텍스트를 표출해서 지도 생성이 가능합니다. ![8.png](https://images.gogumang.com/e9bb252fd8/08.png)
