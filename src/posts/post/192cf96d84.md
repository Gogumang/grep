## 마켓 컬리는 이렇게 일합니다

### 컬리의 팀 구성

컬리에서는 Front-end, Back-end, DevOps 등 해당 기술 스택별로 role 이 나누어져서 팀이 구성되어 있습니다.

![](https://helloworld.kurly.com/_astro/php-developer-division.OFZXeRVN_Z12KDc1.webp)

현재 컬리내 PHP 개발팀은 Back-end 를 맡고 있으며, 위의 로드맵에서의 Front-end, DevOps 로드맵이 동시에 존재하는 이유는 충분히 해당 기술 스택을 습득하고 있으면, 다른 팀간의 커뮤니케이션에 충분히 도움이 될 것이라는 의도입니다.

### 컬리의 CI/CD

![](https://helloworld.kurly.com/_astro/ci-cd.CfPEwUzy_2sL9SL.webp)

컬리는 도커로 배포 하고 있으며, CI/CD 자동 빌드 배포가 됩니다. 그렇기 때문에 PHP + Docker 기술 습득은 필수 과제가 됩니다.

### Modern PHP + Laravel!

컬리는 PHP 개발을 할때 Modern PHP 에 준거해서 개발하고 있고, Laravel 을 이용해서 기존 레가시를 떼어내는 작업을 하고 있습니다.

### 컬리의 MSA

![](https://helloworld.kurly.com/_astro/msa.C_MYCVeA_Z1EwDA0.webp)

컬리는 Spring Cloud Netflix 를 이용해서 마이크로 서비스를 준비중이며, 추후 Kubernetes, Service Mesh 로의 이동을 고려하고 있습니다.
