### KakaoTalk Bizmessage 서비스

최근에 TOAST에 친구톡이라는 기능을 새롭게 마련하면서, 알림톡과 친구톡을 합쳐서 KakaoTalk Bizmessage라는 이름의 서비스로 개편하게 되었습니다.

![메인.png](https://images.gogumang.com/3902a41b46/01.png)

왼쪽은 알림톡 메시지의 한 가지 사례로서 수신자가 카카오톡 플러스친구와 친구를 맺을 필요없이 특정한 이벤트가 발생할 때마다 수신하게 됩니다. 오른쪽은 친구톡 메시지의 한 가지 사례로서 플러스친구와 친구를 맺은 수신자만 광고성 메시지를 수신하게 됩니다.

KakaoTalk Bizmessage 서비스의 친구톡 기능을 이용하여 광고성 메시지를 발송하는 방법에 대해 간단히 설명하겠습니다.

### 플러스친구 등록

TOAST 콘솔에서 조직과 프로젝트를 선택한 후, 서비스선택 버튼을 클릭하여 KakaoTalk Bizmessage 서비스를 활성화합니다. KakaoTalk Bizmessage 서비스의 "플러스친구 관리" 탭으로 이동합니다.

```
조직 > 프로젝트 > Notification > KakaoTalk Bizmessage > 플러스친구 관리
```

우선 KakaoTalk Bizmessage 서비스를 이용하려면 카카오톡 플러스친구를 [카카오톡 플러스친구 관리자센터](https://center-pf.kakao.com/)에서 등록해야 합니다. "플러스친구 생성" 버튼을 클릭하면 카카오톡 플러스친구 관리자센터로 이동합니다.

![2.png](https://images.gogumang.com/3902a41b46/02.png)

그리고 반드시 카카오톡 플러스친구 관리자센터의 관리 메뉴의 상세설정에서 "공개 설정" 항목의 "홈 공개" 설정을 켜준 다음 확인 버튼을 클릭하여 저장하시기 바랍니다. 플러스친구는 카카오의 심사/승인을 거쳐 영업일 기준으로 1\~2일 이후에 사용하실 수 있습니다.

```
카카오톡 플러스친구 관리자센터 > 관리 > 상세설정 > 플러스친구 홈 > 공개 설정 > 홈 공개
```

다시 TOAST 콘솔로 돌아와서, "플러스친구 추가" 버튼을 클릭합니다. 플러스친구 ID와 연락처 정보, 사업자 등록번호 등을 입력한 뒤 "등록" 버튼을 클릭합니다.

![3.png](https://images.gogumang.com/3902a41b46/03.png)

카카오톡에서 인증메시지를 받아서 인증 번호를 입력해주시면 등록 절차는 모두 마치게 됩니다. 이후 수신대상자들이 위에서 등록한 플러스친구와 친구를 맺게 되면 친구톡 메시지를 수신할 준비가 된 것입니다.

### 친구톡 발송

TOAST 콘솔에서 친구톡 탭으로 이동합니다.

```
조직 > 프로젝트 > Notification > KakaoTalk Bizmessage > 친구톡
```

플러스친구 ID와 광고 여부, 예약 발송 여부를 선택하고 내용 필드에 메시지 내용을 기입합니다. 메시지는 텍스트만을 포함할 수 있으며 HTML 태그는 사용할 수 없습니다. 광고성 메시지의 경우에는 야간 시간대에는 발송이 불가합니다.

![4.png](https://images.gogumang.com/3902a41b46/04.png)

이미지를 포함할 수도 있는데, "이미지 관리" 하위탭에서 이미지를 추가한 다음, 발송 하위탭에서 사용 가능합니다.

웹페이지로 연결되거나 앱으로 연결되는 링크를 가진 버튼을 추가할 수도 있습니다.

![5.png](https://images.gogumang.com/3902a41b46/05.png)

발송 버튼을 클릭하기 전에 화면 하단의 수신대상자의 전화번호를 입력해야 합니다.

![6.png](https://images.gogumang.com/3902a41b46/06.png)

전화번호를 모두 입력하고 나서 발송 버튼을 클릭하면 친구톡 메시지 발송이 실행됩니다.

### API를 이용한 발송

TOAST 콘솔에서는 최대 20명의 수신자에게 친구톡 메시지 발송이 가능한데, 그 이상의 수신자에게 메시지를 발송해야 한다면, API를 이용하여 발송하는 것을 권장합니다.

```
POST /friendtalk/v1.1/appkeys/{appkey}/messages
Content-Type: application/json;charset=UTF-8
X-Secret-Key": {secretkey}

{
    "plusFriendId": String,
    "requestDate": String,
    "recipientList": [{
        "recipientNo": String,
        "content": String,
        "imageSeq": Integer,
        "imageLink": String,
        "buttons": [
                {
                    "ordering": Integer,
                    "type": String,
                    "name": String,
                    "linkMo": String,
                    "linkPc": String,
                    "schemeIos": String,
                    "schemeAndroid": String
                }
        ],
        "isAd": Boolean
    }]
}
```

자세한 내용은 [사용자 가이드](https://docs.toast.com/ko/Notification/KakaoTalk%20Bizmessage/ko/friendtalk-api-guide/)에서 확인할 수 있습니다.

### 발송 결과 확인

"발송 결과 조회" 하위탭으로 이동하여 검색 버튼을 클릭하면, 발송 성공/실패 여부를 확인할 수 있습니다.
